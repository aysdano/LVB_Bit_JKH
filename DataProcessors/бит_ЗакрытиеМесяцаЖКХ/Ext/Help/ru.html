Обработка «Закрытие месяца» предназначена для расчета ежемесячных начислений по нормативам, счетчикам и льготам по всем услугам на лицевых счетах, записи их в историю. Обработка формирует документы "Начисления по лицевым счетам", "Начисления по счетчикам", "Начисления льгот по ЛС". После проведения данной операции, редактирование в закрытом периоде запрещено.
