Справочник "Шаблоны выгрузки в ГИС ЖКХ"

1. Назначение справочника

Справочник "Шаблоны выгрузки в ГИС ЖКХ" предназначен для для создания шаблонов заполнения файлов ГИС ЖКХ в Excel формате.

2. Описание реквизитов.

При записи элементов справочника необходимо указать:

  • Период - период актуальности шаблона;
  • Наименование – наименование устанавливают согласно наименования файла ГИС ЖКХ;
  • Путь к шаблону - указывают путь к файлу шаблона ГИС ЖКХ для загрузки в него информации из базы данных, после сохранения элемента справочника файл возможно открыть по кнопке "Открыть макет", а путь забыть. Изменить макет возможно также, указав путь к новому файлу ГИС ЖКХ, сохранив его в элементе справочника;
  • Тип дома ГИС ЖКХ – тип дома ЖД или МКД устанавливается в справочнике «Список зданий», а в шаблоне влияет на набор реквизитов для выгрузки. При формировании файлов происходит отбор домов с указанным реквизитом в шаблоне, если тип дома не указан, в файл будут попадать все дома;
  • Номер начальной строки шаблона(по умолчанию) - устанавливается номер начально строки, с которой будут заполняться данные в файл ГИС ЖКХ;
  • Архивный - признак неактуальности шаблона;
  • Шаблон платежных документов - признак шаблона для выгрузки Платежных документов.

3. Табличная часть.

Редактирование макета(Таблицы значений) – табличная часть, в которую внесены реквизиты Файлов ГЦЖС постранично с указанием номеров столбцов, в который необходимо выгружать данные из базы БИТ ЖКХ.
