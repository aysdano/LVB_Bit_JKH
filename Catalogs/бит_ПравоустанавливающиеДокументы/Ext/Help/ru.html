Справочник "Правоустанавливающие документы"

 

1.      Назначение справочника

 

      Справочник "Правоустанавливающие документы" предназначен для хранения сведений по лицевым счетам о документах, подтверждающих право на проживание/пребывание граждан в жилом помещении. Используется в документах Заявление о регистрации по месту пребывания/жительства 

  

2.      Описание реквизитов.

  

При записи элементов справочника необходимо указать:

  • Наименование – наименование документа, подтверждающего право на жилье, выбирается из справочника Виды документов на жилье ;
  • Номер документа - номер, серия документа по лицевому счету, подтверждающая право на проживание;
  • Дата документа - дата выдачи документа;
  • Организация, выдавшая документ - наименование организации, выдающей документы на право проживания. Реквизит заполняется из справочника Контрагенты.
