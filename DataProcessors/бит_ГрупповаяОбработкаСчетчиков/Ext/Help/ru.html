Групповая обработка счетчиков

ЖКХ ® Счетчики\распределения ® Групповая обработка счетчиков

Обработка «Групповая обработка счетчиков» предназначена для создания однотарифных индивидуальных счетчиков и установки их на лицевые счета.

Групповая обработка счетчиков предоставляет возможность пошагово:

  • Создать элементы справочника "Счетчики", которые могут быть установлены на услуги по лицевым счетам,
  • Установить счетчики на услуги по лицевым счетам, автоматически сформировав документы "Установка\снятие счетчика".

     

    Порядок установки счетчиков на услуги лицевых счетов. Шаг 1 "Создание счетчиков".

    Сформировать список лицевых счетов в табличной части формы можно путем заполнения полей: Улица и Дом.

    Правила формирования наименований счетчиков через поля настройки Состав наименования счетчика. Просмотр результатов настроек виден в табличной части формы при нажатии кнопки Заполнить наименования.

    Создание элементов справочника "Счетчики" осуществляется при нажатии кнопки Создать счетчики.

    Задать правила формирования нумерации счетчиков можно путем выбора значения из поля Нумерация:

    • По порядку - наименование формируется из значения поля Префикс, порядкового номера и Постфикса;
    • По номеру квартиры - наименование формируется из значения поля Префикс,  номера квартиры и Постфикса; 
    • По номеру лицевого счета - наименование формируется из значения поля Префикс,  номера лицевого счета  и Постфикса.

    Порядок установки счетчиков на услуги лицевых счетов. Шаг 2 "Установка счетчиков".

    Заполнить поле Дата установки счетчиков, если дата установки отличается от текущей даты. Выбрать услугу, на которую устанавливается счетчик. В нижней табличной части заполнить начальные и конечные показания счетчиков.

    Документы "Установка\снятие счетчика"формируются при нажатии кнопки Установить счетчики.
