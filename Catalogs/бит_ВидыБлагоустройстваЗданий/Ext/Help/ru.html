Справочник «Виды благоустройства зданий»

1.      Назначение справочника

 

Справочник "Виды благоустройства зданий" предназначен для хранения списка видов благоустройств зданий, использующихся на форме элемента справочника Список зданий. 

 

2.      Описание реквизитов

 

При записи элементов справочника необходимо указать:

  • Наименование – наименование вида благоустройства здания. Справочник имеет два предопределенных значения: Без лифтов и С лифтами.
