Отчет "Оборотные ведомости (услуги по строкам)"

ЖКХ® Отчеты ® Оборотные ведомости (услуги по строкам)

Отчет определяет финансовое состояние в различных разрезах: по лицевым счетам, по лицевым счетам в разрезе услуг, по поставщикам услуг, по услугам и т.д. С помощью Списка вариантов отчета и создания всевозможных новых настроек можно вывести информацию в различных разрезах: по лицевым счетам, по домам, по участкам, по районам, начисления, льготы, оплаты, разовые и т.д.

В отчете возможна Детальная расшифровка сумм: начислений, оплат, разовых начислений, льготных недоплат.

Варианты отчета:

 Оборотные ведомости (услуги по строкам).

2.1.  Оборотная ведомость по ЛС в разрезе услуг

2.2.  Оборотная ведомость по услугам в разрезе поставщиков и лицевых счетов;

2.3.  Оборотная ведомость по поставщикам услуг в разрезе услуг и домов;

2.4.  Оборотная ведомость по поставщикам услуг в разрезе услуг;

2.5.  Оборотная ведомость по домам в разрезе услуг;

2.6.  Оборотная ведомость по услугам в разрезе поставщиков;

2.7.  Оборотная ведомость по услугам в разрезе поставщиков и домов;

2.8.  Оборотная ведомость по ЛС;

2.9.  Оборотная ведомость по расчетам с потребителями;

2.10.               Оборотная ведомость по участкам в разрезе домов.
