Документ «Ввод начальных остатков пени по КУ»

 

1.   Назначение документа

Документ "Ввод начальных остатков пени по КУ" необходим на этапе создания базы данных (когда осуществляется переход на автоматизированную систему расчетов с квартиросъемщиками) при вводе начальных значений начисленной пени для всех лицевых счетов.

Документ «Ввод начальных остатков пени по КУ»

·       ввод начального сальдо пени по КУ – проводятся суммы начального сальдо по пени отдельно по каждой услуге на лицевом счете.

2.   Процедура заполнения

 

Документ заводится через пункт меню ЖКХ/Начисление пени по ЛС/Ввод начальных остатков пени по КУ

В табличной части с помощью клавиатуры вносится вручную "Лицевой счет - Услуга -  Сумма".

С помощью кнопки Подбор можно заполнить табличную часть документа лицевыми счетами.

 

Дата документа должна быть равна последнему дню месяца перед началом ведения расчетов по услугам ЖКХ.

3.   Описание реквизитов

 

В форме документа "Ввод начальных остатков пени по КУ" заполняются следующие реквизиты:

Организация - наименование организации, по которой вводится начальное сальдо на лицевые счета.

Табличная часть:

·        Лицевой счет - номер карточки лицевого счета, по которому вводится начальное сальдо по пени;

·        Табличная часть "Услуга" - наименование услуги на лицевом счете, по которой есть начальное сальдо по пени;

·        Сумма - величина суммы начального сальдо по пени на услуге. 

 

4.   Движение документа при проведении:

При проведении документ формирует движения по регистру накопления Начисления пени по услугам ЖКХ
