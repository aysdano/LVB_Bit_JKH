Справочник «Причины выписки»

 

1.      Назначение справочника

 

      Справочник "Причины выписки" предназначен для хранения разновидностей причины выписки зарегистрированного по лицевому счету гражданина с места проживания/ пребывания. Используется в документе Регистрация проживающих по ЛС .

  

2.      Описание реквизитов.

  

При записи элементов справочника необходимо указать:

  • Наименование – наименование причины выписки зарегистрированного по лицевому счету гражданина с места проживания/пребывания.
