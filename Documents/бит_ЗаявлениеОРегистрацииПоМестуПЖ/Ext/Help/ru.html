Документ Заявление о регистрации по месту пребывания/проживания

 

1.      Назначение документа

Документ "Заявление о регистрации по месту пребывания/ проживания" служит для отражения операций, связанных с пропиской/ выпиской граждан (временно или постоянно) на лицевых счетах. 

- Вид операции "Регистрация по месту пребывания" предназначен для временной регистрации проживающих по месту пребывания, с обязательной выпиской Свидетельства по месту пребывания. Документы хранятся в журнале Журнал учета регистрации граждан по месту пребывания. Имеют печатные формы №1, №2, №3, №4, №5, №12П согласно приказа №208 от 20 сентября 2007 г. Федеральной миграционной службы.

- Вид операции "Регистрация по месту жительства" предназначен для регистрации проживающих по месту жительства, Свидетельство по месту проживания выписывают только детям до 14 лет. Документы хранятся в журнале Журнал учета регистрации граждан по месту жительства . Имеют печатные формы №6, №2, №8, №9, №12П, №13 согласно приказа №208 от 20 сентября 2007 г. Федеральной миграционной службы.

 

На основании документа с вышеперечисленными видами операции вводятся документы Регистрация проживающих по ЛС и Свидетельство по месту пребывания.

 

- Вид операции "Снятие с регистрационного учета" предназначен для ведения учета выписанных граждан по лицевому счету, хранения заявлений и выпуска печатных форм №6, №7, №12В, №14, согласно приказа  №208 от 20 сентября 2007 г. Федеральной миграционной службы. На основании документа с данным видом операции вводится документ Регистрация проживающих по ЛС с выпиской проживающего по ЛС.

 

2.       Процедура заполнения

 

Документ заводится через меню ЖКХ/Паспортный стол/Заявление о регистрации снятии.

При создании нового документа необходимо выбрать нужный вид операции.

 

3.      Описание реквизитов

 

В  форме документа "Заявление о регистрации по месту пребывания/проживания" заполняются следующие реквизиты:

  • Организация – организация, по которой проводится регистрация граждан;
  • Лицевой счет – номер лицевого счета.

Табличная часть "Данные о регистрируемом лице":

  • Регистрируемое лицо – ФИО человека, подающего заявление о регистрации по лицевому счету, значение реквизита выбирается из справочника Физические лица;
  • Дата регистрации – дата начала регистрации по адресу;
  • Дата снятия с рег. – дата окончания срока регистрации по адресу (реквизит присутствует только в операции "Регистрация по месту пребывания");
  • Документ основание – документ, подтверждающий законность регистрации гражданина по ЛС, выбирается из справочника Правоустанавливающие документы;
  • Принятое решение – комментарий о принятии решения по заявлению;
  • Откуда прибыл – перечень возможных мест прибытия (с другого города; в том же городе с другого адреса; смена фамилии; другая причина) для правильного заполнения оборотной стороны Формы №2;
  • Степень родства – реквизит указывает степень родства ответственного лица к регистрируемому гражданину, необходим для заполнения заявления с видом операции "Регистрация по месту жительства", выбирается из справочника Степень родства физических лиц;
  • Ответственный за регистрацию – ответственное лицо на лицевом счете, по которому проводится регистрация. Выбирается из справочника Проживающие. В списке будет только ответственный по лицевому счету;
  • Должностное лицо – ФИО должностного лица организации. Выбор осуществляется из справочника Физические лица. Заполнение макетов данными произойдет, если выбранное физ. лицо является одним из должностных лиц организации, см. регистр сведений "Ответственные лица организации".

Табличная часть "Доп. данные" используется при заполнении макетов:

  • "РФЛ1: Сведения в ГНИ, с детьми до 14 лет" – в макет выводится все, кому не исполнилось 14 лет. Заполнять колонку "Физическое лицо";
  • "Бланк заявления проживания (для СНГ)" и "Бланк заявления пребывания (для РФ)" -  в макет выводятся все, кому исполнилось 18 лет. "Физическое лицо";
  • "Ф6: Заявление о регистрации по месту жительства" и "Ф1: Заявление о регистрации по месту пребывания" – в макет выводится первая запись для заполнения данных законного представителя. Используется в случае, когда регистрируется несовершеннолетний, которому не исполнилось 14 лет.  Заполнять колонки "Физическое лицо" и "Степень родства". Если ответственный за регистрацию и законный представитель одно и то же лицо, то заполнять табличную часть не нужно.

Данные для заполнения макетов регламентированных форм берутся:

  • Данные о рождении, ФИО, паспортные данные, адреса прибытия и убытия – из справочника Проживающие;
  • Адрес прописки – из справочника Список зданий, закладка "Адрес": Почтовый адрес здания;
  • Данные паспортной службы – из справочника Список зданий, закладка "Данные": Паспортная служба;
  • Данные о налоговой службе – из справочника Организации, закладка "Основные": Сведения о регистрации в ИФНС.

Данные по адресам для заполнения макетов нерегламентированных форм берутся:

  • Адрес регистрации ответственного лица – из справочника Проживающие, если заполнен адрес по прописке (см. закладку "Адреса и телефоны"), либо из справочника Список зданий, закладка "Адрес": Почтовый адрес здания, если адрес по прописки не заполнен;
  • Адрес прибытия – из справочника Список зданий, закладка "Данные": Паспортная служба.
