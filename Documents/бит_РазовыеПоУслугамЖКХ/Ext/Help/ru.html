Документ «Разовые по услугам ЖКХ»

 

1.   Назначение документа

 

Документ «Разовые по услугам ЖКХ» предназначен для введения разовых перерасчетов в текущем периоде за предыдущие.

 

2.   Процедура заполнения

 

Заполнение документа производится в зависимости от вида операции.

2.1. Техническая корректировка - на выбранном лицевом счете сумма перерасчета вносится вручную в табличной части "Услуга-Сумма";

2.2. При установке/снятии счетчика - сумма по услуге вычисляется на момент установки/снятия счетчика на ЛС и проведении документа "Установка/снятие счетчика"

 

3.   Описание реквизитов

 

В форме документа "Разовые по услугам ЖКХ" заполняются следующие реквизиты:

·        Лицевой счет - номер карточки лицевого счета, по которому производится перерасчет;

·        Табличная часть "Услуга" - наименование услуги, выбирается из справочника "Услуги";

·        Сумма - величина суммы перерасчета по услуге. 

 

4.   Движение документа при проведении:

При проведении документ формирует движения по регистру накопления Начисления по услугам ЖКХ
