Справочник «Статьи паспорта дома»

1. Назначение справочника

Справочник «Статьи паспорта дома» иерархический, предназначен хранения перечня статей паспорта дома, используемых для формирование Паспортов домов. Данные справочника используются при создании документа «Паспорт дома» для формирования дерева статей паспорта дома.

2. Описание реквизитов

При настройке справочника необходимо указать следующие данные:

  • Наименование - наименование статьи паспорта дома;
  • Наименование полное - полное наименование статьи паспорта дома;
  • Кодификатор - номер статьи, выводимый в отчеты по Паспорта дома;
  • Единица измерения - выбирается из справочника "Классификатор единиц измерения".
