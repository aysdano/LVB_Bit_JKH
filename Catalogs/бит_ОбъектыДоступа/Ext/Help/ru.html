Справочник «Объекты доступа»

В конфигурацию «БИТ:ЖКХ» включен механизм настройки прав доступа к объектам конфигурации в режиме «1С:Предприятие». Это означает, что пользователь программы может настраивать права доступа ко всем объектам системы без привлечения программистов.

Для включения механизма на уровне базы необходимо установить флаг «Использовать разделение доступа на уровне базы» в настройках программы (меню «Настройки параметров ЖКХ» - «Константы»).

Справочник «Объекты доступа» предназначен для хранения объектов, на которые распространяется механизм настройки прав доступа.

 

При добавлении нового объекта конфигурации, он автоматически добавиться в справочник при первом запуске, система проинформирует пользователя о добавлении.

Например, если в конфигурации добавили новый справочник «Тестовый», то сообщение о добавлении нового объекта доступа (при запуске системы) будет выглядеть следующим образом:

Если нет необходимости распространения механизма для нового справочника, тогда необходимо установить флаг «Отключить» в форме элемента справочника «Объекты доступа».

 

Для создания области доступа к объекту доступа необходимо перейти на закладку «Области доступа» и добавить необходимые области (новые области добавляются в справочнике «Области доступа», подчиненном справочнику «Объекты доступа»).

Например, создадим область доступа ограниченную организацией, назовём её «Элементы организации – ТЕСТИРОВАНИЕ».

 

Флаг «Отключить» устанавливается, если нет необходимости использовать данную область доступа.

Затем добавим поле, по которому необходимо выполнять отбор элементов справочника, на которые будут распространяться настройки прав доступа, настроенные на данную область, в нашем случае «Организация».

 

Теперь зададим значение для выбранного поля.

 

 

Область готова к настройке прав доступа.
