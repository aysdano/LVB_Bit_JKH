Документ «Начисления пени по лицевым счетам»

 

1.      Назначение документа

 

Документ «Начисления пени по лицевым счетам» предназначен для начисления пени по лицевым счетам в момент закрытия платежного периода с записью данных в историю т.е. регистр накопления Начисления пени по услугам ЖКХ  и регистр накопления для расшифровки сумм по периодам Начисление пени по периодам.

Документ также формируется на основании документа  Оплата коммунальных услуг .

 

2.     Процедура заполнения

 

Документ заводится через пункт меню ЖКХ/Начисление пени по лицевым счетам/Закрытие платежного периода или Ввод на основании документа Оплата коммунальных услуг  

 

3.     Описание реквизитов

 

В форме документа «Начисление пени по лицевым счетам» заполняются следующие реквизиты:

  • Организация;
  • Улица - наименование улицы, по которой в табличной части производится расчет пени на долги по услугам на лицевых счетах;
  • Строки табличной части - сведения о начислениях пени на долг по всем услугам на лицевых счетах улицы, указанной в шапке документа.  

 

4.      Движения документа при проведении

 

При проведении документ формирует движения по регистрам накопления Начисления пени по услугам ЖКХ и Начисление пени по периодам.
