Обработка «Ввод ПКО на основании Оплаты КУ» предназначена для ввода Приходных кассовых ордеров автоматически на основании документа Оплата КУ. Для формирования ПКО необходимо указать:

- Счет учета

- Статью движения денежных средств

- В окне «Документы оплаты необходимо выбрать очередной документ «Оплата КУ», автоматически будут заполнены реквизиты –

- Источник оплаты,

- Организация,

- Сумма.

- Разбить по лицевым счетам – реквизит, значение которого, по умолчанию стоит «Нет». Формирование ПКО будет происходить одним документом на общую сумму, если указать – «Да», ПКО будут сформированы по каждой строке документа «Оплата КУ» с заполнение значения контрагента из регистра  «Ответственные лица по КУ», сведения в который попадают из документа «Регистрация проживающих по ЛС».
