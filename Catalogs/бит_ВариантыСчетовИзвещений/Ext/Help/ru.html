Справочник "Варианты счет - извещений"

 

      Справочник предназначен для хранения списка вариантов макетов счет-извещений.

В данном справочнике представлена возможности отредактировать внешний вид печатной формы счет-извещения,

либо разработать собственную форму, как на базе одного из основных вариантов, так и полностью новую.

В справочнике представлено несколько предопределенных элементов, это "ОВ ® Основные варианты" счет-извещений.

Алгоритмы заполнения и вывода на печать этих вариантов описаны в обработке "Печать счет-извещений".

 

 На форме представлены следующие элементы управления:

  • Основной вариант                                      - В этом поле необходимо указать предопределенный элемент справочника, как ссылку на алгоритм печати.
  • Использовать пользовательскую функцию - При установке данного флага на форме будет доступна закладка "Пользовательская функция".
  • Закладка "Редактирование Макета"            - На закладке располагается поле табличного документа для редактирования макета, дерево доступных параметров и командная панель.
  • Закладка "Пользовательская функция"      - На данной закладке располагается поле текстового документа в котором необходимо описать алгоритм печати языком 1С.
  • Закладка "Комментарий"                            - На данной закладке находится поле комментарий.

 

     Для начала работы над макетом его необходимо загрузить на форму. Для этого на закладке "Редактирование макета",

воспользуйтесь меню "Загрузка". Макет возможно загрузить из базы на основе ОВ либо из внешнего файла в формате ""mxl".

Редактирование макета выполняется стандартными средствами 1С, на командной панели располагаются кнопки быстрого доступа

для объединения и разъединения ячеек.

     Справа на закладке располагается дерево доступных параметров для вывода данных в макет. Чтобы перенести выбранное поле в макет, выделите

ячейки и щелкните 2 раза ПКМ на поле в дереве.

Описание пользовательской функции:

Код пользовательской функции испольняется в модуле объекта обработки Печать счет-извещени. При описании функции печати используются следующие переменные:

  • мКэшОрганизации  Экспорт             Структура  - хранит информацию по организации
  • мКэшПараметрыЖКХ Экспорт           Структура  - хранит параметры учета ЖУХ и настройки печати.
  • мНастройкиМакета Экспорт              СправочникСсылка, Структура - Хранит настройки печати макета.
  • мОсновнойВариантМакета Экспорт   СправочникСсылка - Хранит основной вариант макета.
  • мВнешняяКомпонента                       COMОбъект  - хранит внешнюю компоненту формирования ШтрихКода
  • мСтруктураДанных                          Структура  - хранит данные шапки печатных документов.
  • мТаблицаПечати                              Таблица значений - Таблица начислений по лицевому счету.
  • мТаблицаПечатиСчетчиков              Таблица значений - Таблица приборов учета.
  • мТаблицаПерерасчетов                   Таблица значений - Таблица перерасчетов по лицевому счету.
  • мМакет                                           Табличный документ - Текущий макет печати

Функция возвращает сформированый табличный документа содержащий данные по одному лицевому счету.
