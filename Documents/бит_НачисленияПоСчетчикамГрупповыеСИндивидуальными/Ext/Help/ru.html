Документ «Начисления общедомовых расходов»

ЖКХ -> Регламентные операции -> Начисления общедомовых расходов

1. Назначение документа

Документ «Начисления общедомовых расходов» является регламентным документом, предназначен для расчета разницы между индивидуальными начислениями и суммы по групповым с индивидуальными счетчикам, распределения ее по лицевым счетам с записью данных в историю т.е. в регистры накопления и регистр сведений. Документ формируется автоматически, путем закрытия месяца обработкой Закрытие месяца ЖКХ. Его можно использовать для проведения расчетов вручную, но только после введенных документов Начисления по лицевым счетам и Начисления по счетчикам.

2. Процедура заполнения

По кнопке «Рассчитать» в табличной части документа заполняются данные по начислениям на услугах по групповым с индивидуальными счетчикам, соответствующих отбору, установленному в шапке документа. Для редактирования в документе доступны поля Дата, Организация, Улица, Здание.

3. Описание реквизитов

В форме документа «Начисление общедомовых расходов» заполняются следующие реквизиты:

  • Организация;
  • Улица, Здание - реквизиты, указывающие наименование улицы и номер дома, по которым в табличной части будет произведен расчет;
  • Строки табличных частей по кнопке "Рассчитать" выводят сведения о начислениях по всем услугам со счетчиками групповыми с индивидуальными на лицевых счетах, указанного в шапке документа, с указанием Лицевого счета, Услуги, Счетчика, Способа распределения, начальных показаний на начало расчетного периода, конечных показаний, разницы показаний, объем по ЛС, ставки и суммы по услугам.

4. Движения документа при проведении

При проведении документ формирует движения по регистрам накопления: Количество единиц по счетчикам, Начисления по счетчикам, Начисления по услугам ЖКХ, Показания счетчиков, Нераспределенный остаток по общедомовым счетчикам, Объемы по услугам ЖКХ.
