Регистр накопления "Начисления по услугам ЖКХ (по периоду)"

1. Назначение регистра.

Регистр накопления "Начисления по услугам ЖКХ (по периоду)" предназначен для хранения сумм начислений, оплат, перерасчетов, льгот, субсидий по услугам на лицевых счетах по периодам. С помощью данных этого регистра формируются акты сверки по лицевым счетам.

2. Регистраторы.

Регистраторы - Документы Начисления по лицевым счетам , Начисления по счетчикам , Начисления общедомовых расходов , Разовые по услугам ЖКХ , Оплата коммунальных услуг , Ввод начальных остатков по КУ
