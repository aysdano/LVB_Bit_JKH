Регистр сведений "Количество единиц по общедомовым счетчикам"

1. Назначение регистра.

Регистр сведений "Количество единиц по общедомовым счетчикам" предназначен для хранения данных о количестве показаний общедомового счетчика. Предназначен для отчетности.

2. Регистраторы.

Документы: Начисления общедомовых расходов.
