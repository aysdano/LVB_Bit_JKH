Создание квартир и лицевых счетов

ЖКХ ® Сервис ® Создание квартир и лицевых счетов

Обработка предназначена для группового создания зданий, помещений и лицевых счетов и  содержит параметры настроек формирования элементов справочника Лицевые счета.

Обработка создания квартир и лицевых счетов предоставляет возможность:

  • Создать список зданий и помещений, для которых будут созданы лицевые счета,
  • Сформировать коды лицевых счетов по правилам, установленным пользователем,
  • Создать элементы справочников Список зданий, Квартиры,  Лицевые счета.

    Порядок формирования списка зданий, квартир, лицевых счетов

     

  • Сформировать список зданий - указать номера первого и последнего дома, которые необходимо создать. По кнопке Заполнить список зданий формируются Здания.
    - Просмотр элементов справочника Список зданий отображается в табличной части Список зданий.

  • Сформировать список квартир - указать период формирования сведений о квартире, Тип квартир, Статус квартир.
     Если необходимо сформировать частные дома, в префиксе проставляют "-" и номера не заполняют, будет сформировано одно помещения без номера квартиры.

  • Сформировать список лицевых счетов по правилам формирования кодов лицевых счетов - указать Префикс ЛС, Постфикс ЛС, Правила нумерации, Длина лицевого счета.

  • Просмотр элементов справочников Квартиры и Лицевые счета отображаются в табличной части Список квартир и лицевых счетов по кнопке Заполнить квартиры и ЛС.
    Создание элементов справочника Лицевые счета и квартиры осуществляется при нажатии кнопки Создать квартиру и ЛС.
