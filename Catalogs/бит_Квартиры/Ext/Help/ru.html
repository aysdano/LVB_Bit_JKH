Справочник «Квартиры»

1.      Назначение справочника

  

Справочник "Квартиры" подчиненный справочнику Список зданий, предназначен для хранения сведений по квартирам. Заполнение производится через справочник "Список зданий"/ закладка "Квартиры". Сведения об изменениях по данным квартиры хранятся в регистре сведений Сведения о квартире.

 

2.      Описание реквизитов. 

·        Номер квартиры + префикс составляют номер квартиры на карточке лицевого счета;

·        Этаж - реквизит заполняется вручную и служит для определения квартир, которые не должны оплачивать за услугу, связанную с лифтами.

·        Кол-во комнат - реквизит заполняется вручную, используется как справочная информация.

·        Сведения о площадях, типе и статусе квартиры описаны в Сведения о квартире
