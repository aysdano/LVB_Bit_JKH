Документ «Смета доходов и расходов»

1. Назначение документа

Документ «Смета доходов и расходов» предназначен для формирования сметы по статьям оборотов сметы доходов и расходов. Сценарий - План.

2. Процедура заполнения

В документах указывают сценарий - План, по которому будут введены статьи оборотов сметы, период заполнения данных.

На закладке «Источники данных» указываются источники данных – список доступных источников данных из одноименного справочника.

По кнопке «Заполнить» в табличной части "Фактические данные" документа заполняются данные источникам данных.
По кнопке «Распределить по зданиям» в табличной части будут распределены суммы по зданиям, указаным в Источниках данных.

3. Описание реквизитов

В форме документа «Смета доходов и расходов» заполняются следующие реквизиты:

  • Организация;
  • Сценарий факт - реквизит, выбирается из справочника "Сценарии";
  • Период - периодсбора данных;
  • Строки табличных частей по кнопкам "Заполнить", "Распределить по зданиям" выводят сведения о суммах в разрезе Статей оборотов сметы..

4. Движения документа при проведении

При проведении документ формирует движения по регистрам накопления: Обороты по сметам.
