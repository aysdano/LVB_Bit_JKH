Регистр накопления "Начисления по услугам ЖКХ"

 

1.      Назначение регистра.

 

      Регистр накопления "Начисления по услугам ЖКХ" предназначен для хранения сумм начислений, оплат, перерасчетов, льгот, субсидий по услугам на лицевых счетах. С помощью данных этого регистра формируются "Счет извещения" на оплату, различные отчеты.

 

2.  Регистраторы.

 

      Регистраторы - Документы  Начисления по лицевым счетам , Начисления по счетчикам , Разовые по услугам ЖКХ , Оплата коммунальных услуг
