Справочник «Шаблоны сметы»

 

1. Назначение справочника

 

Справочник «Шаблоны сметы», предназначен для создания регламентированных или типовых шаблонов Сметы доходов и расходов, используемых при автоматическом заполнении статьями документа Смета доходов и расходов.

 

2. Описание реквизитов

 

Справочник заполняется автоматически по кнопке Заполнить по группе статей оборотов из справочника Статьи оборотов:

  • Наименование - наименование шаблона;
  • Наименование полное - полное наименование шаблона;
  • Статьи паспорта дома - заполняются автоматически из справочника Статьи паспорта дома.
