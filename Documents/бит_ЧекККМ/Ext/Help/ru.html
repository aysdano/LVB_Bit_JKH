Документ "Чек ККМ"

1.      Назначение документа

Документ предназначен для ввода оплат по кассе с разнесением по лицевым счетам и пробитием чека на фискальном регистраторе с подкладной печатью (Прим-07К) как вручную, так и автоматически при помощи сканера штрих кодов.

2.     Процедура заполнения

      Документ заполняется кассиром с помощью обработки «Рабочее место кассира»

3.     Описание реквизитов

·      Код кассы – номер кассы, к которой подключен фискальный регистратор;

·      Код пачки – номер пачки по предприятию, рекомендуемый формат  ККДДММ, где КК – номер кассы, ДД – число месяца, ММ – месяц;

·      Касса  – наименование подразделения предприятия;

·      Лицевой счет – номер лицевого счета, по которому проводится платеж;

·      Шаблон извещений – ссылка на справочник «Шаблоны извещений» с набором услуг к оплате, при необходимости, дана возможность заводить новый шаблон;

·      Сумма оплаты – сумма платежа;

·      Услуги – список услуг с суммами распределения платежа по услугам;

·      Счетчики – отображение счетчиков на лицевом счете для заведения показаний по индивидуальным счетчикам;

·      Заполнить – по кнопке заполнить курсор переходит на заполнение текущих показаний по счетчику;

·      Ввести показания – по кнопке формируется и проводится документ «Ввод показаний по счетчикам»;

·       Получено – сумма, внесенная плательщиком в кассу;

·      Сдача – сумма сдачи плательщику;

·      Кассовый оттиск – кнопка посылает сигнал фискальному регистратору на печать кассового оттиска;

·      Сторнирование – возврат оплаченной суммы с проведением сторнирования по фискальному регистратору;

·      Следующая квитанция – запись документа в журнал для дальнейшего заполнения документа «Оплата КУ»;

4.     Движение документа при проведении

При проведении документ производит запись в регистр накопления Начисления касс.
