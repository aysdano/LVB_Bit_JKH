Форма записи регистра "Настройки источников справочной информации"

Обеспечивает просмотр и редактирование настройки источника справочной информации для конкретного значения параметра сеанса (например, для конкретного пользователя).

 

  • Источник - настраиваемый источник справочной информации
  • Объект - значение параметра сеанса для которого выполняется настройка (например, имя пользователя).
