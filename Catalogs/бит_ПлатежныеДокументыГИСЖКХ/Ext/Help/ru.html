Справочник «Платежные файлы ГИС ЖКХ»

1. Назначение справочника

Справочник "Платежные файлы ГИС ЖКХ" служит для хранения данных, которые используются при формировании Шаблона импорта платежных документов ГИС ЖКХ.

2. Процедура заполнения

Элементы справочника создаются через обработку ЖКХ -> Сервис -> Печать счет извещений по кнопке Заполнить платежные документы ГИС ЖКХ.

3. Описание реквизитов

Реквизиты справочника должны быть заполнены:

  • Лицевой счет, Расчетный период, Шаблон извещений – данные, которые не редактируются и заполняются из обработки Печать счет извещений. Поля обязательное для заполнения;
  • Идентификатор ПД – идентификатор, который заполняется после загрузки Платежных документов на сайт ГИС ЖКХ и присвоения на ему значения на сайте;
  • Отозван – флаг, указывающий, что Платежный документ отозван на сайте ГИС ЖКХ.
