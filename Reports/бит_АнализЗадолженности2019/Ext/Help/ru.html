Отчет "Оборотные ведомости (услуги по столбцам)"

ЖКХ® Отчеты ® Оборотные ведомости (услуги по столбцам)

Отчет предназначен для вывода информацию о разных типах начислений (постоянные, разовые, текущие, льготные, оплата) для выбранных лицевых счетов. С помощью Списка вариантов отчета и создания всевозможных новых настроек можно вывести информацию в различных разрезах: по лицевым счетам, по поставщикам услуг, по домам, по участкам, по районам,  начисления, льготы, оплаты, разовые и т.д.

В отчете возможна Детальная расшифровка сумм: начислений, оплат, разовых начислений, льготных недоплат.
