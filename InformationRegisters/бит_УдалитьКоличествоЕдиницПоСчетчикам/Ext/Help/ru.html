Регистр сведений "Показания по счетчикам(кол. ед.)"

 

1.      Назначение регистра.

 

     Регистр сведений "Показания по счетчикасм"  прденазначен для хранения данных о последних показаниях счетчкиа. Предназначен для отчетности.
