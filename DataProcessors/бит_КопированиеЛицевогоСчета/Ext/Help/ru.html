Обработка «Копирование лицевого счета»

1. Назначение обработки

Обработка "Копирование лицевого счета" служит для создания нового лицевого счета по квартире на основании уже существующего с созданием Установки услуг по лицевому счету и Регистравции проживающих.

2. Процедура заполнения

Обработка вызывается через форму элемента справочника "Лицевые счета" , по кнопке "Скопировать".
