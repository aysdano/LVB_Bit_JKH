Справочник "Поставщики услуг"

 

1.      Назначение справочника

 

      Справочник "Поставщики услуг" предназначен для установки соответствия между поставщиками конкретных услуг и реальным получателем денежных средств. Этот механизм дает возможность в дальнейшем формировать сводные отчеты не только по поставщику отдельной услуги, но и сразу по нескольким услугам для реального получателя денежных средств. 

  

2.      Описание реквизитов.

  

При настройке справочника необходимо указать следующие данные:

  • Наименование – наименование поставщика услуг;
  • Комиссионный сбор.
