Документ «Регистрация проживающих по ЛС»

 

1.      Назначение документа

 

Документ «Регистрация проживающих по ЛС» предназначен для внесения проживающих на лицевой счет, изменения данных о проживающих на ЛС. Документ в финансовом периоде формируется один. Вводится на карточке лицевого счета.

 

2.       Процедура заполнения

 

Документ заводится на закладке «Проживающие» формы ЛС.

По кнопке «Подбор» в табличной части документа заполняются данные о проживающих по адресу ЛС на момент формирования документа или выбираются новые из справочника "Физические лица".

По каждому проживающему можно внести изменения, выписать уже имеющихся или прописать новых.

 

3.      Описание реквизитов

 

В  форме документа «Регистрация проживающих по ЛС» заполняются следующие реквизиты:

  • Физическое лицо – ФИО человека, имеющего отношение к лицевому счету; значение реквизита выбирается из справочника «Физические лица»;
  •  Статус физ.лица – статус проживания физического лица; значение реквизита выбирается из справочника Статусы физ. лица
  • Степень родства – реквизит принимает значение «Ответственное лицо» или отношение проживающего к «Ответственному лицу», выбирается из справочника Степени родства физических лиц ;
  • Статус проживания – реквизит принимает значение Постоянно или Временно. Постоянно – означает постоянную прописку физического лица по адресу ЛС; Временно – временное проживание, например, квартирант;
  • Дата регистрации – дата прописки проживающего по адресу ЛС;
  • Дата снятия с регистрации – дата выписки;
  • Дата окончания статуса – после истечения даты, статус изменяется на «Постоянная регистрация»

 

4.      Движения документа при проведении

 

При проведении документ формирует движения по регистру сведений Проживающие по ЛС .
