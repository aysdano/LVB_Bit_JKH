Документ «Начисления по счетчикам и распределениям»

 

ЖКХ -> Регламентные операции  -> Начисления по счетчикам

 

1.      Назначение документа

 

Документ «Начисления по счетчикам и распределениям» является регламентным документом, предназначен для начисления по услугам со счетчиками (индивидуальными и групповыми) на лицевых счетах, а так же для начисления по распределениям с записью данных в историю т.е. в регистры накопления  и регистр сведений. Документ формируется автоматически, путем закрытия месяца обработкой Закрытие месяца ЖКХ. Его можно использовать для проведения расчетов вручную, а после проведения документа перейти к формированию документа Начисления по лицевым счетам и установить запрет на редактирование документов в прошедшем периоде.

 

2.     Процедура заполнения

 

По кнопке «Рассчитать» в табличной части "По счетчикам" документа заполняются данные по начислениям на услугах по счетчикам как индивидуальным, так и групповым, соответствующих отбору, установленному в шапке документа. Если есть распределения, то заполняется табличная часть "По распределениям". Для редактирования в документе доступны поля Дата, Организация, Улица, Здание.
ВНИМАНИЕ: для счетчиков со способом расчета "По групповым счетчикам" и распределениям со способом расчета "По распределению" необходимо в документе "Установка ставок по услугам" указать основную ставку для квартиры статусом - приватизированная и типом - отдельная. Такой подход обеспечивает единство расчетов независимо от статуса и типа помещений, подключенных к групповому счетчику или распределению. 

 

3.     Описание реквизитов

 

В форме документа «Начисление по счетчикам и распределениям» заполняются следующие реквизиты:

  • Организация;
  • Улица, Здание - реквизиты, указывающие наименование улицы и номер дома, по которым в табличной части будет произведен расчет;
  • Строки табличных частей по кнопке "Рассчитать" выводят сведения о начислениях по всем услугам со счетчиками групповыми и индивидуальными на лицевых счетах и распределениям для здания, указанного в шапке документа, с указанием способа расчета, номера счетчика, источника показаний (население, инспектор, подкрутка), начальных показаний на начало расчетного периода, конечных показаний, разницы показаний, количества показаний на ЛС, ставки и суммы по услугам.

 

4.      Движения документа при проведении

 

При проведении документ формирует движения по регистрам накопления: Количество единиц по счетчикам, Начисления по счетчикам, Начисления по услугам ЖКХ, Показания счетчиков и Распределения, а так же в регистр сведений Источники показаний счетчиков.
