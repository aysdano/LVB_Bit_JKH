Документ «Свидетельство о регистрации по месту пребывания»

 

1.      Назначение документа

 

Документ "Свидетельство о регистрации по месту пребывания" служит для ведения учета выданных документов для временно проживающих граждан на лицевых счетах. Вводится на основаниии Заявление о регистрации по месту пребывания/проживания. Производится запись в Журнал учета регистрации граждан по месту пребывания и формируется отчет по форме №4 согласно приказа №208 от 20 сентября 2007 г. Федеральной миграционной службы.

 

2.       Процедура заполнения

 

Документ вводится на основании Заявление о регистрации по месту пребывания/проживания или заводится через меню ЖКХ/Паспортный стол/Свидетельство о регистрации по месту пребывания.

 

3.      Описание реквизитов

 

В  форме документа должны быть заполнены следующие реквизиты:

  • Организация - организация, по которой проводится регистрация граждан;
  • Лицевой счет - номер лицевого счета;
  • Регистрируемое лицо – ФИО человека, подающего заявление о регистрации по лицевому счету, значение реквизита выбирается из справочника Физические лица;
  • Дата регистрации - дата начала регистрации по адресу;
  • Дата снятия с рег. - дата окончания срока регистрации по адресу;
  • Ответственный за регистрацию - ответственное лицо на лицевом счете, по которому проводится регистрация.
