Регистр накопления "Начисление пени по периодам "

 

1.      Назначение регистра.

 

      Регистр накопления "Начисление пени по периодам", предназначен для хранения сумм начислений по пене, за период, на услугах лицевых счетов. С помощью данных этого регистра, можно получить расшифровку начислений пени в разрезе периодов задолженности, настроенных в справочнике Периоды начисления пени.

 

2.  Регистратор.

 

      Регистратор - Документ Начисление пени по лицевым счетам.
