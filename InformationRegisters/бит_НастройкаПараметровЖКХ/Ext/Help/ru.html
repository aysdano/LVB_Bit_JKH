Настройка параметров ЖКХ

ЖКХ® Настройка параметров ЖКХ

      Регистр предназначен для хранения данных о настройках параметров ЖКХ. Настройка параметров ЖКХ заполняется в начале работы системы или редактируется после закрытия платежного периода. Она определяет для конкретной организации в конкретный период способы взаимодействия различных частей системы и задает правила обработки различных данных. По бухгалтерскому учету определяет счета учета начислений и оплат по собственным услугам и услугам сторонних предприятий.

 

2.  Регистраторы.

 

      Регистр независимый с периодичностью в пределах месяца.

 

Для всех организаций необходимо заполнить данные на закладках:

Константы
Бухгалтерский учет 

Остальные закладки заполняются по мере необходимости.

Организации, пользующиеся фискальным регистратором, могут настроить информацию для вывода в чеке, используя закладку:

Чек ККМ 

Для организации вывода информации в счетах-извещениях используется закладка:

Печать Счет-извещений 

При ведении работы с должниками и формировании бланков претензий, алгоритм расчета сумм долга можно настроить на закладке:

Претензионный учет

При вводе новой записи об учетной политике необходимо:

  • завести дату появления записи, с которой будет применяться данная учетная политика;

  • выбрать организацию из списка собственных организаций.

Константы
Элементы управления на закладке "Константы" позволят настроить алгоритм формирования сумм начислений по услугам в зависимости от учетной политики организации:
  • указать дату, с момента которой будут вестись начисления в регистры накопления;

  • указать дату окончания платежного периода и количество месяцев отсрочки начисления пени. Эти данные нужны при расчете количества дней просрочки платежа для начислений пени;

  • флаг Льгота персонифицированная устанавливается, если суммы льгот начисляются, но не учитываются при формировании общей суммы начислений;

  • флаг Выводить льготы на счет извещение устанавливается для вывода сумм льгот в бланки счетов-извещений;

  • флаг Начислять пени устанавливается, если организация ведет учет пеней по всем лицевым счетам;

  • флаг Расчет с учетом долей владения используется при расчете начислений сумм по услугам от площади владения и сумм льгот на лицевых счетах;

  • флаг Уменьшение нормы льготы до фактического потребления на человека и используется при расчете сумм льгот на лицевых счетах, при установке флага льгота рассчитывается с учетом фактического потребления, приходящегося на одного проживающего;

  • флаг Начисление на проживающих с учетом количества дней проживания позволяет проводить расчет начислений с учетом фактически прожитых дней на лицевом счете. Дни прописки или выписки учитываются при расчете;

  • флаг Расчет по социальным нормам с учетом многотарифного счетчика дает возможность перераспределять количество единиц потребления, не использованные до нормы потребления в одной зоне суток, поровну на другие зоны суток;

  • флаг Счетчики–подкрутка используется для начислений по индивидуальным счетчикам, установленным на услуги в случаях, когда показания по счетчику в месяце вообще не снимались. Установка флага вычисляет количество единиц по услуге при закрытии месяца ЖКХ в зависимости от выбора переключателя. Документ Ввод показаний по счетчикам создается автоматически и формирует начисления по индивидуальному счетчику с видом операции Показания подкрутки;

    • переключатель По норме - выбор переключателя формирует сумму расчета по услуге согласно способа расчета и режима потребления, с которыми установлена услуга на лицевой счет (см. справочник Лицевые счета, закладка «Предоставляемые услуги»);
  • переключатель По среднему за три месяца с переходом в норматив - выбор переключателя формирует сумму расчета по услуге по среднему за три предыдущих месяца. Если в течении трех месяцев подряд были только показания-подкрутки, то способ расчета по этой услуге переключится на способ, как при установке переключателя По норме;
    • флаг Подкрутка на ЛС – установка флага переводит расчет количества единиц по счетчику при подкрутке по норме "На лицевой счет". Действует при установленном значении переключателя По норме или По среднему за три месяца с переходом в норматив (в случае, когда произошел переход расчета со среднего за три месяца на норматив). Данные для расчетов можно увидеть в справочнике Услуги ЖКХ на закладке «Нормы на услуги»;
  • переключатель По среднему – выбор переключателя формирует сумму расчета по услуге по среднему за столько предыдущих месяцев, сколько указано в поле "Количество месяцев подкрутки";
    • группа переключателей «Графа общедомовых расходов» позволяет вести расчет начислений общедомовых расходов на групповые счетчики (со способом расчета - Групповые с наличием индивидуальных) в двух вариантах:

      • переключатель Перерасчет (разовые) – после закрытия месяца документом Разовые по услугам ЖКХ с видом операции По групповым счетчикам с наличием индивидуальных;

      • переключатель Начисления – в момент запуска обработки закрытия месяцадокументом Начисление общедомовых расходов;

        • флаг Учитывать начисления по групповым счетчикам – устанавливается, если на групповом счетчике стоят не только индивидуальные, но и групповые счетчики.

     

    Бухгалтерский учет
    Задаются бухгалтерские счета для формирования бухгалтерских проводок при проведении документов (счета, указанные при описании носят рекомендательный характер):

    Закладка "Основная":

    • Счет абонента - (76.КУ)- счет расчетов по лицевым счетам за предоставляемые услуги. Используется при начислениях: по лицевым счетам, пени по ЛС, льгот по лицевым счетам, при оплате коммунальных услуг, разовых по услугам ЖКХ. Разработчиками предлагается счет 76.КУ, который имеет аналитику в разрезе лицевых счетов;
    • Транзитный счет оплаты – (76.06) - счет зачисления оплат по источникам поступления. Используется при оплате за жилье и коммунальные услуги потребителями через кассу (Приходный кассовый ордер) или банк (Платежное поручение) и для разнесения оплаты за жилье и коммунальные услуги по лицевым счетам (ЖКХ –> Оплата КУ). Он связывает бухгалтерию и модуль ЖКХ;
    • Счет начисления по КУ – (86.03) - счет расчетов по лицевым счетам за коммунальные услуги;
    • Счет целевые средства – (86.03) - счет расчетов по лицевым счетам за эксплуатационные услуги, исполнение и сбор оплаты за которые производит сама организация, при этом организация не имеет прибыли, а все собранные средства тратятся на выполнение тех услуг, на которые денежные средства и собирались. Кроме выше перечисленных документов, счет используется при проведении документа Начисление льгот по лицевым счетам;
    • Счет аренда – (90.01.1) – счет расчетов по аренде, взимаемых самой организацией. По этому счету проходят те услуги, тип начислений которых – аренда;
    • Счет начислений льгот – (75.05) – счет начисления льгот по услугам, плату за которые взимается самой организацией. Используется при начислении льгот по лицевым счетам;
    • Счет расчета по КУ – (76.05) – счет расчетов по лицевым счетам за коммунальные услуги, средства от платы за которые поступают сразу на счета сторонних организаций. Используется при начислении по лицевым счетам, начислении пени по ЛС, начислении разовых по услугам ЖКХ;
    • Счет расчета оплат – (60.01) – счет учета оплат по лицевым счетам за коммунальные услуги, плату за которые перечисляется сторонним организациям через банк или кассу. Используется при распределении оплаты по поставщикам одноименным документом;

    • Счет расчета по льготам

      – (76.05) – счет начисления льгот услугам, средства по оплате за которые взимают сторонние организации. Используется при начислении льгот по лицевым счетам;

      Закладка "Счет дохода":

    • Счет дохода

      – (90.01.1) – счет начисления доходов от выручки (вознаграждения) от поступивших денежных средств по услугам, предоставляемые сторонними организациями. ВНИМАНИЕ: для корректного закрытия месяца обработкой типовой бухгалтерии нужно заполнить аналитику счета.

    Закладка "Счет пени":

    • Счет пени

      – для собственных услуг (90.01.1), для услуг сторонних организаций (76.05) – счета начисления пени.  Счета имеют свою  аналитику.

        Чек ККМ

        Элементы управления на закладке "Чек ККМ" позволят настроить информацию, которая будет печататься на чеке:

      • Печать получателей ДС на чеке ККМ – список выбора для вывода дополнительной информации на чеке по ККМ – поставщиков услуг; 
      • Разбить оплату КУ по датам – важный элемент настроек модуля ЖКХ и может в итоге повлиять на начисление пени. Влияет на дату формирования документа Оплата КУ. Установка флажка позволит программе закрыть чеки оплаты (документом Оплата КУ) датой поступления оплаты в кассу, т.е датой формирования чеков. Снятие флажка установит дату регистрации документа Оплата КУ текущей датой формирования самого документа без учета дат с чеков ККМ;
      • Группировать услуги в чеке – для настройки последовательности печати услуг в чеках ККМ.

        • Печать Счет-извещений
        В счете-извещении есть строка вывода адреса лицевого счета. Для формирования состава адреса по желанию организации, формирую-щей счета-извещения, можно регулировать составом адреса и выводить те части, которые необходимы, с возможностью настраивать префиксы по ус-мотрению пользователя. Не установленные флажки указывают на то, что часть адреса будет участвовать в формировании адреса. Кроме структуры адрсса есть флажки, которые регулируют вывод дополнительной информации и последовательность формирования Счетов-извещений:
        • Выводить замечания ЖКХ на счет извещение – при установленном флажке замечания с Карточек лицевых счетов выведутся в бланки счет извещений;
        • Выводить счета-извещения зависимых ЛС – при установленном флажке счета-извещения зависимых лицевых счетов (те ЛС, счета-извещения которых доставляются не по адресу лицевого счета, а по фактическому адресу плательщика), выведутся в список счет извещений за извещением ЛС–владельца. Применяется для удобства сортировки в пачке распечатанных счетов-извещений;
        • Настройки адреса - группа полей ввода и флажков для организации вывода адреса лицевого счета в бланках Счетов-извещений;
        • Использовать номер получателя в ШК – устанавливается в том случае, если банк, принимающий оплату за коммунальные услуги требует идентификацию организации–получателя денежных средств. Пользователю нужно ввести символы в поле "Номер получателя по банку".

        Претензионный учет
        В модуле ЖКХ есть возможность формирования и печати предупреждений для жильцов, имеющих долги. Пользователь может настроить параметры исчисления суммы долга. Расчет долгов и заполнение макетов для печати пользователь может выполнить через документ «Предупреждение». Настройки:
        • Выводить сумму без учета переплат по услугам – при установке флажка в макет предупреждения сумма задолженности формируется из колонки «Сумма без переплат» табличной части документа «Предупреждение», а при снятом флажке – из колонки «Сумма»;
        • Выводить сумму без учета переплат по услугам – при установке флажка в макет предупреждения сумма задолженности формируется из колонки «Сумма без переплат» , а при снятом флажке – из колонки «Сумма».
