Регистр накопления "Начисление по льготам".

 

1.      Назначение регистра.

 

      Регистр накопления "Начисление по льготам" предназначен для хранения сумм начислений,  перерасчетов по льготам на услугах лицевых счетов. С помощью данных этого регистра ведется учет начисленной льготы.

 

2.  Регистраторы.

 

      Регистраторы - Документы Начисление льгот по лицевым счетам, Разовые по услугам ЖКХ.
