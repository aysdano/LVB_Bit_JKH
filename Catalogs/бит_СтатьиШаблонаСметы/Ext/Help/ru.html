Справочник «Статьи шаблона сметы»

1. Назначение справочника

Справочник «Статьи шаблона сметы», предназначен для хранения перечня статей сметы по Шаблонам, используемых при автоматическом заполнении статьями документа Смета доходов и расходов.

2. Описание реквизитов

Справочник заполняется автоматически при создании элемента справочника Шаблон сметы:

  • Смета - наименование шаблона сметы;
  • Группа - группа статей оборотов Сметы доходов и расходов; 
  • Наименование - наименование статьи Сметы;
  • Наименование полное - полное наименование Сметы;
  • Статья оборотов - наименование статьи Сметы;
  • Кодификатор - номер статьи, выводимый в отчеты по Смете и План-фактному анализу.
