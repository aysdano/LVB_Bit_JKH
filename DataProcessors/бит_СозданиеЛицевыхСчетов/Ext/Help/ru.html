Создание лицевых счетов

ЖКХ ® Лицевые счета ® кнопка Создание лицевых счетов

Обработка предназначена для группового создания лицевых счетов и  содержит параметры настроек формирования элементов справочника Лицевые счета.

Обработка создания лицевых счетов предоставляет возможность:

  • Создать список квартир, для которых будут созданы лицевые счета,
  • Сформировать коды лицевых счетов по правилам, установленным пользователем,
  • Создать элементы справочника Лицевые счета для выбранных пользователем квартир.

    Порядок формирования списка лицевых счетов

    Сформировать список квартир в табличной части формы можно путем заполнения полей: Улица и Дом.

    Правила формирования кодов лицевых счетов через поля настройки Свойства нумерации ЛС для жилых и нежилых помещений. Просмотр результатов настроек виден в табличной части формы при нажатии кнопки Установить номера ЛС.

    Создание элементов справочника Лицевые счета осуществляется при нажатии кнопки Создать ЛС.

    Задать правила формирования кодов лицевых счетов можно путем выбора значения из поля Правила:

    • По номеру квартиры - код формируется из значения поля Префикс,  номера квартиры и Постфикса. Длина кода равна значению поля Длина ЛС. Оставшиеся цифры между префиксом и номером квартиры заполняются нулями;
    • Последовательная нумерация - код формируется из значения поля Префикс,  значения поля Начальный номер и Постфикса. Длина кода равна значению поля Длина ЛС. Оставшиеся цифры между префиксом и номером заполняются нулями.
