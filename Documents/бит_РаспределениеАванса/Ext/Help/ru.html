Документ «Распределение аванса»

1. Назначение документа

Документ «Распределение аванса» предназначен для перерасчета переплат на лицевых счетах по периодам.

2. Процедура заполнения

По кнопке «Заполнить» в табличной части документа заполняются данные по закрытию аванса(переплат) на лицевых счетах по периодам, соответствующих отбору, установленному в шапке документа. Для редактирования в документе доступны поля: Дата, Организация, Улица, Здание.

3. Описание реквизитов

В форме документа заполняются следующие реквизиты:

  • Организация;
  • Улица, Здание - реквизиты, указывающие наименование улицы и номер дома, по которым в табличной части будет произведен расчет;
  • Строки табличной части по кнопке "Заполнить" выводят сведения о перерасчетах переплат по всем услугам на лицевых счетах, здания, указанного в шапке документа.

4. Движение документа при проведении:

При проведении документ формирует движения по регистру накопления Начисления по услугам ЖКХ(по периоду)
