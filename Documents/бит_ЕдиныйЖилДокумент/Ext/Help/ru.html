Документ «Единый жилищный документ»

 

1.      Назначение документа

 

Документ "Единый жилищный документ" служит для подготовки и выдачи единого жилищного документа согласно Постановления №1130-ПП Правительства Москвы от 20 октября 2009 г.

 

2.       Процедура заполнения

 

Документ заводится через меню ЖКХ -> Паспортный стол -> Единый жилищный документ.

Данные документа формируются на актуальную дату:

- дату документа;

- дату, которая заведена в поле "Дата смерти" (см. закладка "Настройки", поле появляется при установке флажка "Справка по смерти") и плюс десять дней.

 

3.      Описание реквизитов

 

В  форме документа должны быть заполнены следующие реквизиты:

  • Организация – организация, по которой проводится регистрация граждан, выбирается из справочника Организации;
  • Административный округ – название административного округа, выбирается из справочника Административные округа;
  • Серия дома – аббревиатура типа домов массовых серий, строка;
  • Лицевой счет – номер лицевого счета, выбирается из справочника Лицевые счета;
  • Физ.лицо – список физических лиц, когда-либо зарегистрированных по выбранному лицевому счету, значение реквизита выбирается из справочника Проживающие. Список формируется ТОЛЬКО при заполненном лицевом счете.

Закладка "Проживающие" используется для заполнения списка зарегистрированных по месту пребывания и проживания. Заполнить можно несколькими способами:

 - кнопка "Заполнить" – позволит заполнить табличную часть из тех лиц, которые прописаны по ЛС на актуальную дату, либо все, кто когда-либо был зарегистрирован по ЛС (см. флажок "Показывать историю проживающих" в табличной части "Настройки"), а так же путем выбора из справочника Проживающие;

- стандартные кнопки панели табличной части.

 

Закладка "Настройки" используется для настройки заполнения параметров макета:

- Параметры вывода полей макета – настройка параметров, которые влияют на алгоритм заполнения макета документа:

 - Заполнять паспортные данные физ. лица – установка флажка заполняет паспортные данные заявителя, если есть на то волеизъявление заявителя;

- Наличие другого жилья – установка флажка отразит в макете документа наличие другого жилья у нанимателя (собственника) и члена его семьи;

-  Показывать историю проживающих – установка флажка сформирует полный список лиц, которые когда-либо проживали по ЛС согласно данных в базе, снятие флажка – формирует список лиц, прописанных на актуальную дату;

- Справка по смерти – установка флажка делает видимым поде "Дата смерти", которое изменяет актуальную дату и меняет процесс заполнения параметров макета;

- Дата смерти – дата, которая меняет актуальную дату для формирования данных по лицевому счету;

- Данные для заполнения полей макета – формирование данных, которые используются в макете документа.

 

Закладка "Коммунальная" появляется в случае, если квартира имеет тип квартиры - коммунальная и  используется для формирования списка квартир, входящих в состав коммунальных. Их отбор осуществляется по зданию и номеру квартиры - если они совпадают, то квартиры заполнят табличную часть. Заполнить можно несколькими способами:

 - кнопка "Заполнить" – позволит заполнить табличную часть из тех лиц, которые прописаны по ЛС на актуальную дату, либо все, кто когда-либо был зарегистрирован по ЛС (см. флажок "Показывать историю проживающих" в табличной части "Настройки"), а так же путем выбора из справочника Проживающие;

- стандартными кнопками командной панели табличной части.
