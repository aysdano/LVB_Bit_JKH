Документ «Начисления по биллинговым услугам»

ЖКХ ® Внешний биллинг ® Начисления по биллинговым услугам 

1.      Назначение документа

Документ «Начисления по биллинговым услугам» предназначен для проведения начислений на лицевых счетах в пределах одного здания, занесения начислений по лицевым счетам в историю для биллинговых услуг.

2.     Процедура заполнения

При добавлении новой строки, выборе лицевого счета и биллинговой услуги оставшиеся колонки заполняются автоматически. Исключение составляет сумма, которую пользователь заносит вручную.

3.     Описание реквизитов

В форме документа «Начисление по биллинговым услугам» заполняются следующие реквизиты:

  • Организация;
  • Улица, Здание - реквизиты, указывающие наименование улицы и номер дома, по которым в табличной части будет произведен расчет;
  • Строки табличной части формируются стандартными кнопками командной панели.

4.      Движения документа при проведении

При проведении документ формирует движения по регистру накопления  Начисления по биллинговым услугам и регистру бухгалтерии  Журнал проводок (бухгалтерский и налоговый учет).
