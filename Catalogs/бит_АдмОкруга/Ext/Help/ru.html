Справочник «Административные округа»

1.      Назначение справочника

 

Справочник "Административные округа" предназначен для для хранения названия округов города.

Здесь можно добавить новый, удалить или отредактировать название уже существующего в базе данных округа.

Данные из справочника используются при формировании единого жилищного документа.

 

2.      Описание реквизитов

 

При настройке справочника указываются следующие данные:

  • Код по ГУ ГЦЖС – код округа согласно городскому центру жилищных субсидий.
  • Наименование – наименование округа.
