Документ «Подключение услуг к зданиям»

 

1.     Назначение документа

 

Документ «Подключение услуг к зданиям» предназначен для создания шаблонов, подключенных услуг к зданиям.

 

2.     Процедура заполнения

 

Документ заводится через пункт меню ЖКХ/Услуги.

 

3.     Описание реквизитов

 

В  форме документа «Подключение услуг к зданиям» заполняются следующие реквизиты:

  • Услуга – наименование услуги, которая будет закреплена к зданию; значение реквизита выбирается из справочника Услуги ЖКХ ;
  • В табличной части вводятся все дома, по которым будет расчитываться услуга.

 

4.     Движения документа при проведении

 

При проведении документ формирует движения по регистру сведений Шаблоны услуг .
