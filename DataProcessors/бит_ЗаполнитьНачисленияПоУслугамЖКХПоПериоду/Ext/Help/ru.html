Обработка «Заполнить начисления по услугам ЖКХ (по периоду)», предназначена для массового заполнения регистра накопления Начисления по услугам ЖКХ (по периоду) в документах Начисления по счетчикам, Начисление по лицевым счетам, Начисление льгот по лицевым счетам, Начисление общедомовых расходов, Оплата КУ, Разовые по услугам ЖКХ, Ввод начальных остатков по КУ с распределением Аванса по периодам.
