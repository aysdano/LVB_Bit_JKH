Настройка соответствия целевого финансирования

ЖКХ® Регламентные операции ® Операции по бухгалтерскому учету ® Настройка соответствия целевого финансирования

1.  Назначение

 

      Регистр Настройка соответствия целевого финансирования предназначен для хранения данных при организации поиска проводок по счету 20.01 "Основное производство". Данные регистра используются документом Закрытие счетов. Количество записей может быть столько, сколько нужно для корректного закрытия счета 20.01.

 

2.  Регистраторы

 

      Регистр независимый с периодичностью в пределах месяца.

 

3.  Данные для заполнения

 

     При вводе новой записи необходимо заполнить следующие реквизиты:

  • Период - завести дату появления записи, с которой будет применяться настройка;

  • Организация - выбрать организацию из списка собственных организаций;

  • Номенклатурная группа - выбрать номенклатурную группу, по которой делались проводки на счет 20.01 "Основное производство" из справочника Номенклатурные группы;

  • Счет целевого финансирования - выбрать субсчет счета 86 "Целевое финансирование" - корреспондирующий счет, на который в дальнейшем будет перенос денежных средств со счета 20.01 без начисления налогов;

  • Назначение целевых средств - выбрать аналитику для выбранного счета целевого финансирования из справочника Назначения целевых средств.
