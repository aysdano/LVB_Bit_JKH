Документ «Разовые по биллинговым услугам»

1. Назначение документа

Документ «Разовые по биллинговым услугам» предназначен для введения разовых перерасчетов в текущем периоде за предыдущие.

2. Описание реквизитов

В форме документа "Разовые по услугам ЖКХ" заполняются следующие реквизиты:

· Лицевой счет - номер карточки лицевого счета, по которому производится перерасчет;

· Табличная часть "Услуга" - наименование услуги, выбирается из справочника "Услуги";

· Сумма - величина суммы перерасчета по услуге.

3. Движение документа при проведении:

При проведении документ формирует движения по регистру накопления Начисления биллинговых услуг
