Документ «Распределение оплаты по поставщикам (Биллинговые услуги)»

ЖКХ ® Внешний биллинг ® Распределение оплаты по  поставщикам 

1.      Назначение документа

Документ «Распределение оплаты по поставщикам» предназначен для формирования бухгалтерских проводок по биллинговым услугам, предоставляемым сторонними поставщиками. Формируется аналогично документу «Распределение оплаты по поставщикам».

2.     Процедура заполнения

Заполнить поля: Организация и Документ основание. При нажатии кнопки Распределить колонки табличной части заполняются автоматически.

3.     Описание реквизитов

В форме документа «Начисление оплаты по поставщикам» заполняются следующие реквизиты:

  • Организация;
  • Документ основание - ссылка на список документов «Оплата биллинговых услуг»;
  • Строки табличной части формируются кнопкой Распределить командной панели.

4.      Движения документа при проведении

При проведении документ формирует движения по регистру бухгалтерии  Журнал проводок (бухгалтерский и налоговый учет).
