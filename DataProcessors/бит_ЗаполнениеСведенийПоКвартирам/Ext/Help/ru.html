Обработка «Заполнение сведений по квартирам»

 

1.      Назначение обработки

 

Обработка "Заполнение сведений по квартирам" служит для массового заполнения свойств квартир. Данные по квартирам используются как для выбора алгоритма расчета за услуги, так и при самих расчетах. Кроме того, в отчетах и макетах, а так же, информационно, во многих объектах базы. Основной из них - Карточка лицевого счета.

 

2.       Процедура заполнения

 

Обработка вызывается через форму элемента справочника "Список зданий" , закладка "Квартиры", нажатием кнопки "Добавить/удалить группу квартир", которая покажет/скроет дополнительную командную панель.  На дополнительной панели кнопкой "Заполнить свойства квартир" вызывается обработка "Заполнение сведений по квартирам" (ЖКХ -> Учет жилого и нежилого фонда-> Список зданий).

Данные по квартирам, сохраняющиеся в регистре сведений "Сведения о квартире" формируются на дату, соответствующую значению:

- реквизита формы справочника "Список зданий - "Период свед. о кв.";

- даты, установленной на компьютере (если обработка вызвана не через форму элемента справочника "Список зданий") .

 

Используя кнопку "Подбор" на командной панели табличной части, пользователь вызовет форму подбора квартир дома "Квартиры".

 

Массово добавить квартиры из формы подбора "Квартиры" в табличную часть обработки можно, зажав клавишу на клавиатуре SHIFT и щелкая правой кнопкой мыши по нужным квартирам. Список выделенных элементов подкрасится синим цветом. Выделив нужные квартиры, нажать кнопку "Выбрать" на форме подбора "Квартиры". Табличная часть формы обработки заполнится тем списком, что был выделен пользователем ранее.

ВНИМАНИЕ: если выделенный список квартир не отобразился в табличной части формы обработки, то это означает, что квартира была создана позднее, чем установлен период сведений. Вернитесь на форму элемента справочника "Список зданий" и на закладке "Квартиры" пройдитесь в табличной части по колонке "№ квартиры", вызвав форму элемента справочника "Квартиры", где на закладке "Сведения о квартире" замените дату записи на более раннюю.

 

 Формирование данных по квартирам происходит по кнопке "Заполнить сведения", одновременно производя записи в регистр сведений Сведения о квартире и отражая данные в табличной части. Период записи в регистр сведений равен выбранному периоду в реквизите "Период сведений" формы обработки. 

 

3.      Описание реквизитов

 

В  форме обработки должны быть заполнены следующие реквизиты:

  • Здание – здание, по которому производится отбор квартир, выбирается из справочника Список зданий;
  • Период сведений – месяц, на который пройдет запись в регистр сведений Сведения о квартире.

 

       Табличная часть используется для заполнения списка квартир по выбранному зданию и формирования данных по площадям и другим сведениям квартир.

 

       Подборка реквизитов "Сведения о квартире для изменения" предназначена для массового заполнения значениями аналогичных данных по квартирам в табличной части.
