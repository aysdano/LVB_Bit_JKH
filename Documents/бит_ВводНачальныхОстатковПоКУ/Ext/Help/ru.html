Документ «Ввод начальных остатков по КУ»

 

1.   Назначение документа

Документ "Ввод начальных остатков" необходим на этапе создания базы данных (когда осуществляется переход на автоматизированную систему расчетов с квартиросъемщиками) при вводе начальных значений сальдо для всех лицевых счетов.

Введение начального сальдо так же позволяет устанавливать начальное значение сальдо для лицевого счета, вновь введенного в текущем финансовом периоде.

Документ «Ввод начальных остатков по КУ»

·        ввод интегрального начального сальдо – в данном режиме сальдо на лицевой счет вводится в виде одной суммы и, затем, эта сумма автоматически разбивается по услугам. Разбиение суммы начального сальдо по услугам происходит пропорционально начислениям по этим услугам

·        ввод дифференциального начального сальдо – при использовании данного режима пользователь имеет возможность вводить суммы начального сальдо отдельно по каждой услуге

Выбор нужного режима работы осуществляется выбором типа операции ввод интегрального или дифференциального начального сальдо.

2.   Процедура заполнения

 

Заполнение документа производится в зависимости от вида операции.

2.1. Ввод интегрального сальдо - в табличной части с помощью цифровой клавиатуры вносится вручную "Лицевой счет - Сумма";

2.2. Ввод дифференциального сальдо  - в табличной части с помощью клавиатуры вносится вручную "Лицевой счет - Услуга -  Сумма".

Дата документа должна быть равна последнему дню месяца перед началом ведения расчетов по услугам ЖКХ.

3.   Описание реквизитов

 

В форме документа "Ввод начальных остатков" заполняются следующие реквизиты:

Организация - наименование организации, по которой вводится начальное сальдо на лицевые счета.

Табличная часть:

·        Лицевой счет - номер карточки лицевого счета, по которому вводится начальное сальдо;

·        Табличная часть "Услуга" - наименование услуги на лицевом счете, по которой есть начальное сальдо;

·        Сумма - величина суммы начального сальдо по услуге. 

 

4.   Движение документа при проведении:

При проведении документ формирует движения по регистру накопления Начисления по услугам ЖКХ
