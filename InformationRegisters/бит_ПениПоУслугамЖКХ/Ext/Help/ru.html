Регистр сведений "Пени по услугам ЖКХ"

 

1.      Назначение регистра.

 

Регистр сведений "Пени по услугам ЖКХ" предназначен для хранения ставок пени по услугам.

       

2.  Регистраторы.

 

Регистр независимый, заполняется выводом формы через меню ЖКХ/Начисление пени по ЛС/Пени по услугам ЖКХ.
