Документ «Предупреждение»

 

1.      Назначение документа

 

Документ "Предупреждение" служит для автоматизированного формирования сумм задолженностей по оплате на момент времени, выбранный пользователем.

 

2.       Процедура заполнения

 

Документ заводится через меню ЖКХ -> Предупреждения.

Данные документа записываются в регистр сведений «Предупреждения жильцам». Сумма долга записывается с учетом настроек ее формирования в регистре сведений «Настройка параметров ЖКХ», закладка «Претензионный учет».

 

3.      Описание реквизитов

 

В  шапке документа должны быть заполнены следующие реквизиты:

  • Организация – организация, по которой проводится регистрация граждан, выбирается из справочника Организации. Поле обязательное для заполнения;
  • Объект выбора – выбор из списка зданий (элементы справочника Список зданий) или лицевых счетов (элемент справочника Лицевые счета), которые обслуживает организация. Если нужно сформировать полный список должников по организации, тогда поле заполнять не нужно;
  • Срок погашения – дата, к которой должник обязан, по мнению организации, оплатить свои долги. При незаполненном значении в макете предупреждения не будет заполнено срока погашения;
  • Дата расчета – дата, с которой производятся расчет долгов. Причем момент расчета долгов проходит от Даты расчета за минусом данных из регистра сведений «Настройка параметров ЖКХ», см. закладка "Константы": Количество месяцев отсрочки платежей и  Последний день приема платежей. При незаполненной Дате расчета берется Дата документа;
  • Мин сумма долга – заполнение поля позволит сформировать список должников, сумма долгов у которых будет больше, чем указанная в поле.

Табличная часть используется для заполнения списка данными должников.

Заполнить можно способами:

 - кнопка "Заполнить" – позволит заполнить табличную часть по установленным настройкам шапки документа;

- стандартные кнопки панели табличной части - скорректировать сформированный или создать новый список табличной части.

 

Колонки табличной части содержат информацию:

- Лицевой счет – список лицевых счетов, имеющих долги по оплате за коммунальные услуги:

- Ответственное лицо – физическое лицо, являющееся ответственным по лицевому счету, элемент справочника Проживающие";

- Сумма без переплат – сумма долга, в которой переплаты по услугам не учитываются при ее формировании;

- Сумма – сумма долга, в которой переплаты по услугам полностью учитываются при ее формировании;

- Сумма пени – сумма пени, которые имеют жильцы перед организацией. Отрицательные числа означают переплату жильцов по пеням.

 

На нижней командной панели формы документа выводится справочная информация:

  • Дата расчета долгов - дата, с которой рассчитывается сумма долга. Оплата, произведенная должником за период от Даты расчета долгов до Даты расчета документом учитывается.

    Кроме справочной информации на нижней командной панели есть управляющие элементы - кнопки печати, формирующие бланки предупреждений для вывода на печать или сохранения во внешних файлах.
