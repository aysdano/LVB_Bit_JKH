Редактирование файла макета

Внесение изменений в макет может выполнятся интерактивно, так и с помощью элементов формы.

Таблицы "Макеты областей"
Таблица предназначена для описания типов и имен областей вывода в печатную форму.
При помощи команды: {v.8} "Открыть область" на позицию курсора в документе вставляется идентификатор c именем области как обозначение начала области содержащей данные для вывода. 
При помощи команды: {/v.8} "Закрыть область" на позицию курсора в документе вставляется идентификатор c именем области как обозначение конца области содержащей данные для вывода.
Описание областей может содержать только один макет с типом: "ВерхнийКолонтитул" и "НижнийКолонтиту".

Доступные типы:
   - ВерхнийКолонтитул (Текст и параметры) ;

   - Таблица (Строка коллекции);
   - Список (Строка коллекции в виде списка);

Таблицы "Параметры"
Таблица предназначена для описания коллекции параметров области.
Параметрами области являются ссылки на реквизиты объекта печати.
Параметры области с типом макета "Список" и "Таблица" могут содержать, как реквизиты табличной части.
При помощи команды: {v.8} "Вставить параметр" на позицию курсора в документе вставляется идентификатор c именем параметра.

Для начала обозначения областей в документ, нажмите на кнопку "Продолжить".
Как правило, никаких специальных действий для запуска нужной программы выполнять не требуется, достаточно кликнуть по файлу макета, и нужная программа запустится автоматически (при условии, что она установлена).

Программа, с помощью которой можно отредактировать макет, определяется типом (форматом) макета:
