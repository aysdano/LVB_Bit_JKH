Регистр накопления "Количество единиц по счетчику"

1. Назначение регистра.

Регистр накопления "Количество единиц по счетчику" предназначен для хранения разницы показаний по счетчикам в разрезе услуг на лицевых счетах. С помощью данных этого регистра формируются различные отчеты.
