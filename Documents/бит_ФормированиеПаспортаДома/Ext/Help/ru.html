Документ «Паспорт дома»

1. Назначение документа

Документ «Паспорт дома» позволяющий заполнить данные Паспорта дома, вывести на печать и сохранить в формат, необходимый для информационного взаимодействия между органами местного самоуправления и лиц, осуществляющих поставки ресурсов, необходимых для предоставления коммунальных услуг, и(или) оказывающих коммунальные услуги в многоквартирных и жилых домах либо услуги (работы) по содержанию и ремонту общего имущества собственников помещений в многоквартирных домах, при предоставлении информациидля формирования сметы по статьям оборотов сметы доходов и расходов. Сценарий - План.

2. Процедура заполнения

Статьи документа заполняются в соответствии с Шаблоном паспорта дома, значения заполняются вручную, один раз создав документ, его возможно копировать, чтобы в дальнейшем вносить изменения в паспорт дома.

3. Описание реквизитов

В форме документа «Паспорт дома» заполняются следующие реквизиты:

  • Организация - организация, которой принадлежит дом;
  • Здание - здание( дом), для которого формируется Паспорт дома, выбирается из справочника Список зданий;
  • Шаблон паспорта дома - шаблон, в котором собраны статьи Паспорта дома, предназначен для автоматического заполнения документа, выбирается из одноименного справочника;
  • Информация о приказе - данные о приказе (постановлении) для подставления в документ: Номер приложения, Дата приказа, Номер приказа;
  • Заголовок отчета - наименование формы Паспорта дома, заполняется вручную;
  • Ответственный за формирование документа» лицо, ответственное за формирование документа Паспорта дома, выбирается из справочника Физические лица;
  • Отчетный период» -период, за который предоставляется информация по дому

 

Строки табличных частей:

  • - «Кодификатор» – номер по порядку в группе статей, заполняется в справочнике «Статьи паспорта дома», в документе заполняются автоматически;
  • «Статья паспорта дома» – наименования статьи Паспорта дома, заполняется автоматически, но возможно откорректировать;
  • «Единица измерения» – единица измерения статьи Паспорта дома, заполняется автоматически, возможно выбрать из справочника Кодификатор единиц измерения;
  • «Выводит в шапку» – реквизит принимает значение Да/Нет. Да - означает вывод информации вне табличной части как заголовок раздела;
  • «Выводит во все колонки» – реквизит принимает значение Да/Нет. Да означает вывод подраздела выделенным шрифтом по всей строке таблицы;
  • «Информация» – данные заполняются вручную информацией по дому постатейно.
