Отчет "Выписка из домовой книги"

ЖКХ® Паспортный стол ® Выписка из домовой книги


Отчет Выписка из домовой книги предназначен для формирования Выписки из домовой книги и Домовой (поквартирной) книги. Данные по проживающим группируются следующим образом: прописанные на дату отчета, либо когда-то проживающие по ЛС, либо на то лицо, которое выбрано в поле выбора "Проживающий". Отчет используется для предоставления в различные инстанции.

Отчет составляется на определенную дату и по выбранному лицевому счету.

Настройки отчета:

  • Флаг "Показывать историю проживающих" - при установленном флажке в выписку попадут данные обо всех людях, когда-либо живших в квартире (на л/с). При снятом флажке - только данные о людях, проживающих на момент выдачи выписки. По умолчанию флажок снят;
  • Флаг "Формировать на одного" - при заполнении поля в выписку попадут данные только по проживающему, указанному в поле ввода "Проживающий". По умолчанию справка формируется на всех зарегистрированных по лицевому счету;
  • Поле выбора "Проживающий" - выбор из списка, отчет сформируется только на то лицо, которое выбрано в поле. Если поле не заполнено, то отчет заполняется данными с регистра сведений "Проживающие по ЛС";
  • Флаг "История прописки" - показывает адреса неоднократного перемещения с адресов в адреса в процессе жизни. По умолчанию флажок снят.
    Пример: Иванов А.В. зарегистрирован в квартире с 01.01.2004 по 25.06.2006 и с 06.09.2010 по настоящее время. При установленном флажке для Иванова А.В в справке будет две строки:
    1. Иванов А.В. с 01.01.2004 по 25.06.2006
    2. Иванов А.В. с 06.09.2010
    При снятом флажке в справку попадет только последняя строчка:
    1. Иванов А.В. с 06.09.2010
