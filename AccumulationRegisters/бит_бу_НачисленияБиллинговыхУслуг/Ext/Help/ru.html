Регистр накопления "Начисления по биллинговым услугам"

1. Назначение регистра.

Регистр накопления "Начисления по биллинговым услугам" предназначен для хранения сумм начислений, оплат, перерасчетов по биллинговым услугам на лицевых счетах. С помощью данных этого регистра формируются "Счет извещения" на оплату, различные отчеты.

2. Регистраторы.

Регистраторы - Документы Начисления по биллинговым услугам , Разовые по биллинговым услугам  , Оплата биллинговых услуг
