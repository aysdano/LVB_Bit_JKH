Документ Заявление ТСЖ

1. Назначение документа

Документ "Заявление ТСЖ" служит для создания списков членов товарищества собственников жилья.

- Вид операции "Вступление в ТСЖ" предназначен для регистрации Собственников жилья во вступление в ТСЖ.

- Вид операции "Выход из ТСЖ" предназначен для регистрации Собственников, вышедших из ТСЖ.

2. Процедура заполнения

Документ заводится через меню ЖКХ/Учет членов ТСЖ/Заявление ТСЖ.

При создании нового документа необходимо выбрать нужный вид операции.

3. Описание реквизитов

В форме документа "Заявление ТСЖ" заполняются следующие реквизиты:

  • Организация – организация, по которой проводится регистрация граждан;
  • ТСЖ – наименование ТСЖ, которому принадлежит здания выбранной организации.

Табличная часть:

  • Лицевой счет - лицевые счета по зданиям, у которых имеются Владельцы квартир, имеющих право вступать в ТСЖ;
  • Проживающий – ФИО человека, подающего заявление о вступлении в ТСЖ;
  • Количество голосов – количество головов(членов семьи владельца), которое учитывается при голосовании;
  • Дата вступления – дата вступления в ТСЖ;
  • Дата выхода - дата выхода из состава ТСЖ.
