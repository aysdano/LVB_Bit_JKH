Справочник «Кассы ККМ»

1.      Назначение справочника

Справочник "Кассы ККМ" предназначен для регистрации касс (денежных ящиков контрольно-кассовых машин), которые используется при оплате за услуги ЖКХ. Кассы ККМ разделены по организациям: для каждой организации может быть определено любое количество касс ККМ.

Денежные средства, полученные при оплате Услуг ЖКХ, поступают в кассу ККМ. 
В кассе ККМ также указывается то Подразделение организации, которому принадлежит касса.
