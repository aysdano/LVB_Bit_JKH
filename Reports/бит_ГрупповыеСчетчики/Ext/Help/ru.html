Отчет "Групповые счетчики"

ЖКХ® Отчеты ® Групповые счетчики

Отчет предназначен для формирования истории начислений по групповым счетчикам. В отчет выводятся данные: ставки на услуги; количество начальных и конечных показаний счетчика; количество единиц, приходящихся на лицевой счет; сумма начислений по каждому лицевому счету. При незаполненных значениях периода формируется отчет за предыдущий месяц.

Пользователь может настроить отчет, создав собственные варианты отбора: по зданию, услуге, счетчику.  Выводимые данные возможно настраивать с помощью кнопок "Настройка..." и  "Все действия -> Настройка".
