Документ «Установка ставок по услугам»

 

1.   Назначение документа

 

Документ «Установка ставок по услугам» предназначен для введения ставок по услугам и поставщикам этих услуг, в зависимости от режимов потребления.

 

2.   Процедура заполнения

 

Документ заводится и редактируется через справочник Услуги ЖКХ.

 

3.   Описание реквизитов

 

В форме документа "Установка ставок по услугам" заполняются следующие реквизиты:

·         Организация - Наименование организации

·         Услуга - наименование услуги;

·         Табличная часть - Ставки по услуге

·         Поставщик - наименование поставщика услуги;

·         Режим потребления - режим потребления услуги;

·         Способ расчета;

·         Статус квартиры - приватизированная/ неприватизированная;

·         Тип квартиры - отдельная/ коммунальная;

·         Плановая ставка - ставка, утвержденная постановлениями;

·         Основная ставка - ставка, по которой ведутся начисления на ЛС;

·         Сверхнормативная ставка - ставка, утвержденная постановлениями, для случая потребления услуги свыше нормы;

4.   Движение документа при проведении:

 

При проведении документ формирует записи в регистр сведений Ставки на услуги
