Справочник "Шаблоны квартир"

1. Назначение справочника

 

     Справочник "Шаблоны квартир" предназначен для создания типовых наборов комнат в квартирах.

  

2. Описание реквизитов.

При записи элементов справочника необходимо указать:

  • Наименование – наименование шаблона квартир;

3. Табличная часть "Комнаты".

Список комнат, которые присутствуют в типовой застройке по квартирам - Жилая комната, Коридор, Ванная и т.п.
