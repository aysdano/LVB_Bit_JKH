Документ «Ввод показаний по счетчикам»

 

1.      Назначение документа

 

Документ «Ввод показаний по счетчикам» предназначен для внесения показаний по индивидуальным и групповым счетчикам.

 

2.     Процедура заполнения

 

Документ заводится на закладке «Данные по счетчикам» формы ЛС для индивидуальных счетчиков в случае показаний по одному ЛС, в случае массового внесения показаний по счетчикам документ заводится через меню ЖКХ.

По кнопке «Заполнить» в табличной части документа заполняются данные по счетчикам, соответствующие отбору, установленному в шапке документа. Для редактирования в документе доступны поля Номер, Дата и Текущие показания.

 

3.     Описание реквизитов

 

В  форме документа «Ввод показаний по счетчикам» заполняются следующие реквизиты:

  • Тип счетчика – индивидуальный или групповой;
  • Услуга – наименование услуги, по которой вводятся показания счетчиков, по кнопке "Заполнить" в табличной части заполнятся все счетчики, установленные в базе по выбранной услуге заданного типа;
  • Население/Инспектор – флаг, указывающий кем сняты показания. Показания группового счетчика сняты Инспектором;
  • Улица, дом, ЛС – реквизиты, указывающие наименование улицы, номер дома, ЛС, по которым в табличной части будут выведены установленные счетчики;
  • Строки табличной части выводят сведения об установленных счетчиках, для корректировки доступно поле – Текущие показания;  

4.      Движения документа при проведении

 

При проведении документ формирует движения по регистру накопления Показания счетчиков
