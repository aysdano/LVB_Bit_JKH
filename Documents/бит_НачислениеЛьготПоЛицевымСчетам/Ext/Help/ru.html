Документ «Начисление льгот по лицевым счетам»

 

1.      Назначение документа

 

Документ «Начисление льгот по лицевым счетам» является регламентным документом, предназначен для проведения начислений по льготам на всех лицевых счетах, где имеются льготники, с записью данных в историю т.е. регистры накопления:  Начисления по услугам ЖКХ и Начисление по льготам.

Документ создается в конце месяца обработкой "Закрытие месяца ЖКХ", либо вручную.

 

2.     Процедура заполнения

 

Документ формируется через пункт меню ЖКХ -> Регламентные операции

По кнопке «Рассчитать» в табличной части документа заполняются данные по начислениям льгот на услугах лицевых счетов, соответствующих отбору, установленному в шапке документа. Для редактирования в документе доступны поля: Дата, Организация, Улица, Здание.

 

3.     Описание реквизитов

 

В форме документа «Начисление льгот по лицевым счетам» заполняются следующие реквизиты:

  • Организация;
  • Улица, Здание - реквизиты, указывающие наименование улицы и номер дома, по которым в табличной части будет произведен расчет;
  • Строки табличной части по кнопке "Рассчитать" выводят сведения о начислениях по всем услугам на лицевых счетах, здания, указанного в шапке документа, с указанием способа расчета, ставки и норм по услугам.  

 

4.      Движения документа при проведении

 

При проведении документ формирует движения по регистрам накопления: Начисления по услугам ЖКХ и Начисление по льготам, регистру бухгалтерии Журнал проводок (бухгалтерский и налоговый учет).
