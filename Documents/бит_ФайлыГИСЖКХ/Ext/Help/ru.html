Документ «Файлы ГИС ЖКХ»

1. Назначение документа

Документ "Файлы ГИС ЖКХ" служит для заполнения файлов ГИС ЖКХ данными, согласно Шаблонов импорта в ГИС ЖКХ в Excel формате.

2. Процедура заполнения

Документ создается через меню  ГИС ЖКХ -> Файлы ГИС ЖКХ.

3. Описание реквизитов

В шапке документа должны быть заполнены следующие реквизиты:

  • Шаблон выгрузки ГИС ЖКХ – шаблон, согласно которому происходит выборка данных в файл ГИС ЖКХ;
  • Организация – наименование организации, по лицевым счетам которой происходит выборка данных в файлы ГИС ЖКХ;
  • Путь к файлу – указывают путь к файлу на жестком диске, в который будет помещена информация, при указании обязательно выбрать файл или записать наименование файла для создания на диске;
  • Настройка отборов – при необходимости устанавливают значения отборов выгрузки по Улицам, Домам, Лицевым счетам;
  • Сформировать – по кнопке формируется файл для импорта в ГИС ЖКХ, содержимое файла возможно проверить в самом документе - Открыть документ или на жестком диске по пути к файлу.
