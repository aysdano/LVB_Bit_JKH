Документ «Регистрация льгот по ЛС»

 

1.      Назначение документа

 

Документ «Регистрация льгот по ЛС» предназначен для внесения льгот на лицевой счет по проживающим на лицевом счете льготникам. Документ вводится на карточке лицевого счета.

 

2.       Процедура заполнения

 

Документ заводится на закладке «Льготы» формы ЛС.

По кнопке «Подбор из списка проживающих» открывается справочник "Физические лица" с отбором проживающих на лицевом счете.

По каждому проживающему можно внести его льготу.

 

3.      Описание реквизитов

 

В форме документа «Регистрация льгот по ЛС» заполняются следующие реквизиты:

  • Лицевой счет - номер лицевого счета по которому устанавливаются льготы. При заведении документа на форме карточки лицевого счета реквизит заполняется автоматически.
  • Физическое лицо – ФИО человека, зарегистрированного по лицевому счету; значение реквизита выбирается из справочника «Физические лица»;
  •  Льгота – наименование льготы; значение реквизита выбирается из справочника Список льгот
  • Срок действия льготы – дата, указывающая срок окончания действия льготы на лицевом счете, вводится из документа удостоверяющего льготу. При наступлении данного срока льгота автоматически перестает действовать, начисления прекращаются; 
  • Документ на льготу, Номер льготного документа, Дата выдачи, Кем выдан - реквизиты указывающие сведения о документах, удостоверяющих право на льготу;

4.      Движения документа при проведении

 

При проведении документ формирует движения по регистру сведений Льготы по лс.
