Документ «Оплата биллинговых услуг»

1. Назначение документа

Документ «Оплата биллинговых услуг» предназначен для ввода оплаты по лицевым счетам, распределения ее по услугам, согласно выбранного шаблона. Данным документом можно вводить оплату за биллинговые услуги как по одному лицевому счету, так и пачками, поступающими из различных источников сбора платежей.

2. Процедура заполнения

Документ заводится через пункт меню ЖКХ/Внешний биллинг/Оплата биллинговых услуг. По кнопке «Подбор» из справочника лицевые счета можно подобрать список лицевых счетов по адресу или номеру лицевого счета.

3. Описание реквизитов

В форме документа «Оплата биллинговых услуг» заполняются следующие реквизиты:

· Организация – наименование организации, по которой распределяются платежи;

· Источник оплаты – сторонняя организация или собственное подразделение, которые занимаются сбором платежей;

Табличная часть – заполнение табличной части для облегчения ввода платежей настроено на ввод с цифровой клавиатуры:

· Лицевой счет – номер лицевого счета плательщика;

· Сумма – сумма оплаты;

· Шаблон извещений – шаблон, содержащий сведения об услугах, на которые будет распределяться оплата и способе распределения оплаты (по входящему сальдо или по текущим начислениям);

· Адрес – вспомогательный реквизит, позволяющий контролировать правильность ввода лицевого счета по адресам.

При вводе оплаты с использованием сканера и штрихкодирования на счет-извещениях все реквизиты табличной части заполняются автоматически.

В дополнительном окне по кнопке «Записать» можно просматривать распределение суммы на лицевом счете по услугам.

4. Движения документа при проведении

При проведении документ формирует движения по регистру накопления Начисления биллинговых услуг
