Справочник «Статьи оборотов»

1. Назначение справочника

Справочник «Статьи оборотов» иерархический,  предназначен хранения перечня статей оборотов, используемых  для формирование расходной и доходной частей сметы эксплуатации жилищного фонда. Данные справочника используются при создании документа «Смета доходов и расходов» для формирования дерева статей оборотов.

2. Описание реквизитов

При настройке справочника необходимо указать следующие данные:

  • Наименование - наименование статьи оборотов;
  • Наименование полное - полное наименование статьи оборотов;
  • Кодификатор - номер статьи, выводимый в отчеты по Смете доходов и расходов;
  • Направление - Доход/Расход;
  • Вид статьи.
