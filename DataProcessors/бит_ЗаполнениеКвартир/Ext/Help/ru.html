Обработка «Заполнение квартир»

1. Назначение обработки

Обработка "Заполнение квартир" служит для массового заполнения покомнатного списка квартир. Данные по комнатам квартир используются:

- при формировании отчета "Копия финансово-лицевого счета" с видами отчета: Полный и Основной;

- при установке индивидуальных счетчиков в документе "Установка/снятие счетчика" для ситуации, когда при формировании бланков счетов-извещений в обработке "Формирование счет извещений" устанавливается флаг "Печатать срочное донесение о показаниях водосчетчиков"

2. Процедура заполнения

Обработка вызывается через форму элемента справочника "Список зданий" , закладка "Квартиры", нажатие кнопок "Добавить комнаты" и "Заполнение комнат" (ЖКХ -> Учет жилого и нежилого фонда-> Список зданий).

Данные, сохраняющиеся в регистре сведений "Сведения о комнате в квартире" формируются на дату, соответствующую значению:

- реквизита формы справочника "Список зданий - "Период свед. о кв.";

- даты, установленной на компьютере (если обработка вызвана не через форму элемента справочника "Список зданий") .

3. Описание реквизитов

В форме обработки должны быть заполнены следующие реквизиты:

  • Организация – организация, по которой проводится отбор;
  • Здание – здание, по которому производится отбор квартир, выбирается из справочника Список зданий;
  • Колво комнат – число, количество жилых комнат квартиры. См. форму элемента справочника "Список зданий" , закладка "Квартиры", табличная часть, колонка "Комнаты". По умолчанию значение - 0, что сформирует полный список квартир;
  • Шаблон квартир – название шаблона, покомнатный состав которого будет использоваться при формировании списка комнат, выбирается из справочника Шаблоны квартир.

Закладка "Данные квартир" используется для:

- заполнения списка квартир по выбранному зданию с учетом количества комнат. Для квартир, покомнатный состав следует заполнить, нужно проверить установку флажка в колонке "Применять настройки". По умолчанию, флаг установлен у каждой квартиры списка. Кнопками на панели инструментов можно управлять состоянием всех флажков списка квартир;

- формирования списка комнат по кнопке "Заполнить", если выбран шаблон квартир, либо стандартными средствами панели инструментов.

Закладка "Настройки шаблона" используется для массового заполнения покомнатного состава квартир в части высоты и площади комнат. Эти данные попадут в регистр сведений "Сведения о комнате в квартире". Если данные закладки не заполнять, то данные по площади и высоте придется заполнять для каждой квартиры отдельно.
