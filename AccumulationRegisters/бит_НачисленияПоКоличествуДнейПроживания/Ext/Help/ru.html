Регистр накопления "Начисление по количеству дней проживания".

 

1.      Назначение регистра.

 

      Регистр накопления "Начисление по количеству дней проживания" предназначен для хранения сумм начислений по услугам лицевых счетов с учетом дней проживания зарегистрированных лиц на лицевом счете. С помощью данных этого регистра ведется учет количества дней проживания и сумм начислений по услугам, зависящих от основного Способа расчета - по проживающим.

 

2.  Регистраторы.

 

      Регистраторы - Документы Начисление по лицевым счетам.
