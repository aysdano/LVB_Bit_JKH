Документ «Справка о составе семьи»

 

1.      Назначение документа

 

Документ "Справка о составе семьи" служит для формирования справок о составе семьи для проживающих граждан на лицевых счетах.

 

2.       Процедура заполнения

 

Документ вводится через меню:  ЖКХ –> Паспортный стол –> Справка о составе семьи.

 

3.      Описание реквизитов

 

В  форме документа заполняются следующие реквизиты:

  • Организация – организация, по которой проводится регистрация граждан;
  • Лицевой счет – номер лицевого счета, заполняется из справочника Лицевые счета;
  • Физ. лицо – ФИО человека, на имя которого выписывается справка. Значение реквизита выбирается из справочника Проживающие;
  • Для предъявления – текст, который в дальнейшем заполнит данные места предъявления.

4.      Описание реквизитов табличной части

Для заполнения табличной части используются стандартные кнопки командной панели и кнопки:

  • Заполнить –> По лицевому счету – автоматическое формирование списка проживающих по выбранному лицевому счету;
  • Заполнить –> Подбор из справочника "Проживающие" – подбор из одноименного справочника.

Реквизиты табличной части:

  • Физическое лицо – физические лица, список которых заполнит табличную часть справки. Заполняется из справочника Проживающие;
  • Родственные отношения – заполняется из справочника Степени родства физических лиц. При автоматическом заполнении табличной части данные берутся из базы, см. справочник Карточка лицевого счета;
  • Дата рождения – данные автоматически заполняются из справочника Проживающие при заполнении реквизита табличной части Физическое лицо.
