Документ «Ввод сумм по распределениям»

 

1.      Назначение документа

 

Документ «Ввод сумм по распределениям» предназначен для внесения сумм необходимых распределить на группу лицевых счетов.

 

3.     Описание реквизитов

 

В  форме документа «Ввод сумм по распределениям» заполняются следующие реквизиты:

  • Улица, дом, ЛС – реквизиты, указывающие наименование улицы, номер дома, ЛС, по которым в табличной части будут выведены установленные распределения;
  • Услуга – наименование услуги, по которой вводятся суммы, по кнопке "Заполнить" в табличной части заполнятся все распределения, установленные в базе по выбранной услуге заданного типа;
  • Строки табличной части выводят сведения об установленных распределениях, для корректировки доступно поле – Сумма;  

4.      Движения документа при проведении

 

При проведении документ формирует движения по регистру накопления Распределения
