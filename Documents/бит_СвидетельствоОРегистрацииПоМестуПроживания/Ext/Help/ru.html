Документ «Свидетельство о регистрации по месту проживания»

 

1.      Назначение документа

 

Документ "Свидетельство о регистрации по месту проживания" служит для ведения учета выданных документов для проживающих граждан младше 14 лет на лицевых счетах. Вводится на основаниии Заявление о регистрации по месту пребывания/проживания. Производится запись в Журнал учета регистрации граждан по месту жительства и формируется отчет по форме №13 согласно приказа №208 от 20 сентября 2007 г. Федеральной миграционной службы.

 

2.       Процедура заполнения

 

Документ вводится на основании Заявление о регистрации по месту пребывания/проживания или создается через меню ЖКХ/Паспортный стол/Свидетельство о регистрации по месту проживания.

 

3.      Описание реквизитов

 

В  форме документа должны быть заполнены следующие реквизиты:

  • Организация - организация, по которой проводится регистрация граждан;
  • Лицевой счет - номер лицевого счета;
  • Регистрируемое лицо – ФИО человека, подающего заявление о регистрации по лицевому счету, значение реквизита выбирается из справочника Физические лица;
  • Ответственный за регистрацию - ответственное лицо на лицевом счете, по которому проводится регистрация, заполняется из справочника Пользователи.

4.  Заполнение макетов

  • Из справочника Проживающие заполняются данные ФИО, места и даты рождения, паспортные данные;
  • Адрес места жительства заполняется из справочника Проживающие, закладка "Адреса и телефоны" – Адрес по прописке. В случае, если Адрес по прописке не заполнен, адрес берется из справочника Список зданий, закладка "Адрес"  – Почтовый адрес здания;
  • Данные по органу регистрационного учета берутся из справочника Список зданий, закладка "Данные" –  Паспортная служба. Если тип данных паспортной службы справочник Контрагенты, то фамилия руководителя заполняется из справочника Контрагенты, закладка "Контакты" –  заполненное контактное лицо, выделенное как основное.
