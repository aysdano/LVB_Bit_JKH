Справочник «Документы для перерасчетов»

1.      Назначение справочника

 

Справочник "Документы для перерасчетов" предназначен для внесения списка наименований документов, подтверждающих право на введение перерасчетов (разовых) на лицевых счетах.

Здесь можно добавить новый, удалить или отредактировать название уже существующего в базе данных документа.

Создание перечня документов, подтверждающих право на перерасчет, позволяет контролировать причину снятия или дополнения суммы по услуге.

 

2.      Описание реквизитов

 

При заполнении справочника необходимо указать следующие данные:

 

·   Группа - наименование группы в справочнике;

·   Контрагент - наименование Поставщика услуг или другого юридического лица, выдавшего документ на перерасчет;

·   Номер – номер документа для перерасчетов;

·   Дата - дата выдачи документа;

·   Наименование – наименование документа;
