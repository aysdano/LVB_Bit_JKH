Справочник "Счетчики"

 

1.      Назначение справочника

 

Справочник «Счетчики» предназначен для хранения сведений о счетчиках, установленных в базе, при расчете начислений по счетчикам на лицевых счетах.

 

2.      Описание реквизитов

  • Серийный номер - серийный номер установленного счетчика по услуге на ЛС, заносится при установке счетчика на ЛС по данным абонентной книжки;
  • Вид счетчика - разновидность видов счетчиков, в зависимости от услуг, реквизит заполняется выбором из справочника "Виды счетчиков";
  • Тип счетчика - принимает значение Групповой или Индивидуальный. Индивидуальный счетчик устанавливается на карточке лицевого счета, Групповой- в справочнике " Список зданий на закдадке "Групповые счетчики";
  • Максимальное значение - реквизит предназначен для введения максимального числа, которое может показывать счетчик, определяет число перехода счетчика через ноль, вносить можно только цифру 9;
  • Коэф.умножения - коэффициент умножения счетчика, при расчете начислений, разность показаний будет перемножаться на этот коэффициент, в большинстве случаев он равен 1;
  • Объект учета - номер ЛС или дома, по которому установлен счетчик. Заполняется автоматически после проведения документа Установка/снятие счетчика
  • Дата установки - дата установки счетчика по адресу;
  • Дата снятия - дата снятия счетчика;
  • Начальные показания - начальные показания счетчика при установке;
  • Кон. показания - конечные показания счетчика;
  • Услуга - услуги, на которые устанавливается счетчик, содержатся в табличной части;
  • Способ расчета - способ расчета по счетчикам.

Последние 7 реквизитов справочника заполняются при установке счетчика на ЛС или здание документом Установка/снятие счетчика
