Документ «Начисления по лицевым счетам»

ЖКХ ® Регламентные операции ® Начисление по лицевым счетам 

1.      Назначение документа

Документ «Начисления по лицевым счетам» является регламентным документом, предназначен для начисления по лицевым счетам с записью данных в историю, т.е. регистр накопления Начисления по услугам ЖКХ , после проведения документа необходимо сформировать отчет "Проверка начислений по услугам ЖКХ" и выявить ошибки в начислениях, если таковых не обнаружится, установить запрет на редактирование документов в прошедшем периоде.

2.     Процедура заполнения

По кнопке «Рассчитать» в табличной части документа заполняются данные по начислениям на услугах лицевых счетов, соответствующих отбору, установленному в шапке документа. Для редактирования в документе доступны поля: Дата, Организация, Улица, Здание.

3.     Описание реквизитов

В форме документа «Начисление по лицевым счетам» заполняются следующие реквизиты:

  • Организация;
  • Улица, Здание - реквизиты, указывающие наименование улицы и номер дома, по которым в табличной части будет произведен расчет;
  • Строки табличной части по кнопке "Рассчитать" выводят сведения о начислениях по всем услугам на лицевых счетах, здания, указанного в шапке документа, с указанием способа расчета, ставки и норм по услугам.  

4.      Движения документа при проведении

При проведении документ формирует движения по регистрам накопления  Начисления по услугам ЖКХ, Начисление по количеству дней проживания и  регистру бухгалтерии Журнал проводок (бухгалтерский и налоговый учет).
