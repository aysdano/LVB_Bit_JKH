Регистр накопления "Начисление пени по лицевым счетам"

 

1.      Назначение регистра.

 

      Регистр накопления "Начисление пени по лицевым счетам" предназначен для хранения сумм начислений, оплат, перерасчетов по пене на услугах лицевых счетов. С помощью данных этого регистра ведется учет начисленной и оплаченной суммы пени.

 

2.  Регистраторы.

 

      Регистраторы - Документы Начисление пени по лицевым счетам , Ввод начальных остатков пени по КУ , Оплата коммунальных услуг .
